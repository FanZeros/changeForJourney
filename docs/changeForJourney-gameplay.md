## 1. 游戏概览

- **类型**：**横屏三栏**（设计分辨率 1080×2400 竖屏稿 → 横屏三联布局，见 `core/Viewport.lua`）放置型卡牌 RPG，暗黑魔塔画风（近黑暖底 / 铁灰 / 骨白 / 血红-余烬点缀）。
- **运行形态**：`main.lua` 直接加载 `boot/Standalone.lua` —— 单机进程内规则层（`rules/`，原多人 Server 目录）+ `LocalActionBridge` 本地直调；存档单文件 `standalone_save.json`（`boot/StandaloneSave.lua`）。多人 Client/Server 壳、MockConnection、`network/` 目录已删除。
- **战斗形态**：**全自动放置，三行并行**（`ui/battle/tri/BattleTriPage.lua`：最多 3 支队伍同屏各自打各自的关）。无手动操作、无怒气/能量、无主动技能；英雄按各自攻击间隔自动普攻，天赋全部为被动 / 概率触发。无编队的行完全不显示敌人。编队未实质改变时不重置战斗（按队 diff 签名）。
- **核心循环**：推关 → 击杀掉落 + 挂机收益 → 装备 / 神器 / 遗物 / 天赋 / 转职养成 → 推更高难度 → 终焉神殿 → 轮回。

## 3. 战斗系统（`systems/CombatFormula.lua` / `ui/battle/combat/BattleCombat.lua` / `AttributeDef.lua`）

### 3.1 流程
- 按 `atkProgress += dt/interval` 累积普攻；战斗速度按钮循环 **1.0 / 1.5 / 2.0**。
- 目标选择：敌方**威胁加权随机**（ThreatManager）；治疗目标选**血量百分比最低**；多目标攻击的额外目标取仇恨最高。
- 胜利 = 敌人全灭；失败 = 己方全灭，1.5s 后**自动撤退到上一关**（无任何惩罚），无独立重试按钮。
- **首通限时 300 秒**，超时判负"时间到!"；挂机（非首通）无限时。

### 3.2 伤害管线（按序）
命中判定 → 基础攻击 × atkCoeff → 增伤（全局 + 物/魔分系加算）→ 暴击（默认暴伤 200%）→ 破甲（有效护甲=max(0,armor−pen)，溢出护甲转为额外穿透加成）→ 连击段数 → 伤害浮动 → 连击增伤 → 暴击倍率 → **类型克制倍率** → ×(1−抗性) → 圣物加成 → 格挡 → 向下取整（保底 1）。

- 命中率 = `(命中值+150)/(闪避值+150)`。
- 抗性 = `0.01×armor / (0.01×armor+1)`。
- 格挡：概率可超 100%（必格 + 余数概率）；默认减伤 60%，上限 80%；多次格挡乘法叠加。
- 连击：≥100% 必出 + 余数概率；额外一段延迟 0.1s 到达。
- 治疗独立公式：治疗量 × atkCoeff × (1+治疗加成) × |克制倍率| × 治疗暴击；**过量治疗**部分触发圣物回调（如艾尔温转为能量护盾）。

### 3.3 类型克制矩阵（攻击类型 × 护甲类型）

行=攻击类型（其归属：斩击/粉碎/穿刺=物理，火焰/冰霜/闪电/暗影=魔法，神圣=治疗），列=皮甲/轻甲/重甲/板甲/布甲：

| 粉碎 | 1.20 | 1.10 | 0.75 | 0.60 | 1.40 |
| 穿刺 | 0.90 | 1.20 | 1.10 | 0.85 | 1.60 |
| 火焰 | 1.15 | 1.10 | 1.25 | 1.40 | 0.75 |

### 3.4 六围派生（AttributeDef META / DERIVATIVES）
例：STR 每点 +1 物攻 / +0.5% 物伤 / +1 护甲 / +5 HP；LUK 每点 +0.3% 暴击率 / +1.5% 暴伤。完整派生表见 `systems/AttributeDef.lua`。

## 6. 挂机与离线收益（`systems/OfflineCalc.lua` / `config/IdleIncomeConfig.lua`）

- **击杀率**：每 3 秒 1 只（`IDLE_KILL_RATE = 1/3`，在线/离线一致），只驱动装备/卷轴种子；金币与经验按分钟查表，不足 1 分钟无收益。
- **离线时长软顶 + 7 日硬顶**：`FULL_RATE_SECONDS = 86400`（前 24 小时满额），`TAIL_RATIO = 0.5`（超出部分按 50% 计），`HARD_CAP_SECONDS = 604800`（**7 日硬顶**：收益与掉落都只按前 7 日计，超出部分不产生任何收益）。弹窗进度条以 24 小时为满格，文案提示软顶与 7 日封顶规则；触顶时显示「离线超过7日，已按上限结算」。**离线奖励弹窗中的奖励图标可点击查看**：装备弹遗匣同款只读详情（`EquipmentDetail.drawReadOnly`），资源弹名称+数量信息卡，点击任意处返回。
- 公式：`金币/经验 = 该关每分钟收益 × 有效分钟数`；英雄经验 = 玩家经验 × 出战人数倍率。
- 收益锚 = 最高首通进度（进行中取上一关）；掉落锚可不同。金币只跟挂机锚点关卡有关，与远征等级无关。
- **关卡扫荡券**：1 券 = 10 分钟挂机收益（金币+双倍经验，`REWARD_MINUTES=10`）+ 固定装备与卷轴，只扫最高已通关。

## 8. 神器（2026-09-27 按代码复核）

- **开放与抽取**：主线抵达噩梦难度后可从教堂·神器页「宝箱」子页签抽取（原市场·典藏页）；每日一次免费单抽按 UTC+8 自然日刷新。付费单抽消耗 1 把金钥匙、十连消耗 10 把；不足时使用已有钥匙并以 **600 黑晶/把**补齐，不足则拒绝抽取。原始品质权重普通/优质/稀有/史诗 = **75/20/4/1**；连续 20 抽无稀有及以上则第 20 抽至少稀有，连续 100 抽无史诗及以上则第 100 抽至少史诗（优先判史诗保底，抽到史诗同时清零两种计数）。原始抽池无传说/至臻；免费抽同样推进保底。背包上限 **300 件**，不足十连容量时整单拒绝。
- **16 种神器**：1 影羽斗篷、2 星辉护符、3 生命棱镜、4 命运纺锤、5 巨人之铠、6 神圣十架、7 左誓战旗、8 右誓法典、9 血誓圣杯、10 亡魂之祭、11 嘲讽面具、12 神徒之骰、13 狂怒沙漏、14 审判官之锤、15 魔王之瞳、16 双生壁垒。6/10/16 最低史诗，15 **仅至臻**且同品质权重为其他类型的一半；低品质神器合成无法获得原本不开放的类型。
- **装配（2026-09-28 三队行式布局）**：**每支队伍（1~3）各自维护一套装配表**，教堂神器页以**三行同时显示**（队1/队2/队3 各占一行，替代原队伍页签切换），每行 = 队标签 + 4 号位列 × 2 子格（行高 330 = 2×160 子格 + 10 间距）；队2/队3 按远征等级 10/20 解锁（未解锁行整体置灰）。每队共 **4 个出战位置**（编号 1–4），每个位置 **2 个神器子格**；第 1/2 格分别于远征等级 **30/60** 解锁（2026-09-28 由 3 格 1/40/80 改版；旧档第 3 格装配自动卸下、实例回背包不丢失）。**缄默礼拜堂本身 30 级开放**（城镇教堂建筑等级门控 + 引导期豁免；终焉古树不受此门控）。**同一实例可同时装到多支队伍（实例可复用）**，但在同一队内只能装一次；同一个出战位置内不能同时装相同类型；左右战旗仅影响本队相邻位置。装配对应**队伍内出战位置**（不是英雄永久绑定），当前战斗通常下一波刷新后生效。存档标识 `id` 是实例 ID，`artifactId` 才是类型 ID，不得混用。
- **养成**：合成消耗 **3 件同类型同品质的未装配神器**，产出 1 件更高品质的同类型神器（至臻不可合成）；教堂可批量一键合成当前满足条件的分组。置换消耗 **2 件同品质、未装配的神器**，产出 1 件同品质的**不同类型**神器（排除两件输入的类型），优先从剩余背包中该品质可产出的持有数量最少的类型中按权重抽取。**「未装配」指任意一支队伍都未装配**——实例可跨队复用后，只要有一队装着就不能合成/置换（服务端与教堂 UI 守卫一致）。合成/置换都重新随机数值，并分配新实例 ID。洗练消耗 **1 特权点**，重新随机该神器全部数值（包括星辉护符的次词条）；结果可能变低，不是保底提升。只在**所有可洗数值均已到上限**时禁止继续洗练。
- **数值与存档**：每件神器以万分比 `valueRatio`（星辉护符另有 `threatClearRatio`）存随机分位，再按当前品质区间换算并四舍五入到 0.1；倒序区间（如影羽斗篷）也按上下界排序后换算，故初值范围不变。`ArtifactSchema` 将完整背包与**按队伍的装配表**压缩为 `av/b/et/n/r/p/t/s/df` 保存（`et[teamIdx][slot][subSlot]`；旧档的全局 `e` 读取时自动迁移为队1 装配，队2/3 从空表开始），读取旧值时归一化；`drawStats` 记录抽取次数和类型/品质统计。养成后已装备外的神器需重新装配才进入战斗。
- **战斗接入**：`ArtifactBridge.applyToUnit(attrs, partySlot, data, teamIdx)` 将面板/战力可见的被动与运行时效果挂到战斗单位；`teamIdx` 缺省 1（主线 BattleScene 等旧调用不受影响），`getDeployedTeam(teamIdx)` 按本队装配表构建，单位携带 `artifactTeamIdx` 供波次间属性刷新（BattleScene/BattleAllyReset）回读正确的队伍装配；每队战力缓存（`refreshPowerCache`）也按本队神器计算。`ArtifactRuntime` 处理闪避衰减、护盾破裂仇恨、反击、复活/亡魂、审判叠层等。拥有「血誓圣杯」的单位由 `UnitAttributes:heal` 阻断生命恢复；「神圣十架」与「亡魂之祭」每场各限首次触发。不要把神器面板战力分等同于实际伤害。

**已确认并修复的逻辑问题**：独立战线曾在重置时清空全部神器状态，现按单位列表重置、按本战线单位计时；三行挂机战线已接入神器首次死亡拦截及亡魂十秒计时；审判官之锤切换目标时删除旧目标叠层；影羽斗篷每次闪避按初始 +200% 的 X% 衰减（以前误把 X 直接当百分点）。战斗运行时效果复制到独立状态，避免重复初始化污染单位持有的效果定义。以上已完成静态审查及官方构建，尚需在实际战斗场景逐项验收。

### 21A.5 数值比较应怎么做

英雄六围为`基础+成长×(等级−1)`，另有共通等级基础HP／ATK成长。主攻击类别决定等级ATK落物攻还是魔攻，神圣治疗却读取`HEAL_AMOUNT`而非MAG_ATK，见`HeroConfig.lua:457`、`CombatFormula.lua:418`。**同魔攻／同面板战力不等于奶量或队伍贡献相同。**

#### 原伤复制与护甲条件

普攻传抗性到`takeDamage`；统一额伤未传时抗性默认0，见`UnitAttributes.lua:478`。不是所有固定技能都绕甲：通宵斩、星门等会在上游自行算抗性。

无盾、无其他乘区，原伤D、抗性r：

```text
普攻实际 = D(1-r)
45%复制额伤 = 0.45D
额伤/普攻实际 = 0.45/(1-r)
```

r=50%时变90%，r=80%时变225%。这是条件公式，不是已测的全局倍率；是否允许“穿甲复制”应产品确认。无面25%、赌徒30%、万剑回收池同理，不能用文字比例直接评估高甲战斗。

#### 摘星与小黑子优先采样

忽略暴击、状态、护甲、增伤、目标死亡和窗口损失，星门未觉醒单门的名义量：`24/3 + (24×3)/2.6 ≈35.692×魔攻/秒`。Ⅰ阶已经提速至2.2秒、单门系数3.4：`24/3 + (24×3.4)/2.2 ≈45.091×魔攻/秒`。Ⅱ共鸣两门：`24/3 + 2×(24×4)/2.2 ≈95.273×魔攻/秒`，仍没计第三门、星痕、提速与共鸣。这说明**必须优先校准k是否重复进入技能预算**，不是已证明该角色绝对第一。

小黑子连射粗略再生产率：`R=每轮弹数×每弹平均连击数/连射门槛`。R≥1可能持续产生后续轮次，但受队列、死亡、命中和重置影响，**没有证实无限递归**。应记录每轮启动与实际弹数。

永久成长很多无层数硬封顶，消费处部分有上限。无上限只是长期风险，当前三行缺死亡事件不能推断已经无限成长。修事件后应按离线／在线积累速度、阶段收益和稀有度投资重新定预算。
