## 1. 游戏概览

- **类型**：竖屏（1080×2400）放置型卡牌 RPG，暗黑魔塔画风（近黑暖底 / 铁灰 / 骨白 / 血红-余烬点缀）。
- **运行形态**：`main.lua` 检测 `multiplayer.enabled=false` 后走 `network/LocalHost.lua` —— 进程内启动完整 Server + LocalCloud（JSON 落盘），客户端请求经 MockConnection 本地直调。无真实联网，但保留多人管线。
- **战斗形态**：**全自动放置**。无手动操作、无怒气/能量、无主动技能；英雄按各自攻击间隔自动普攻，天赋全部为被动 / 概率触发。
- **核心循环**：推关 → 击杀掉落 + 挂机收益 → 装备 / 神器 / 遗物 / 天赋 / 转职养成 → 推更高难度 → 终焉神殿 → 轮回。

## 3. 战斗系统（`systems/CombatFormula.lua` / `ui/battle/combat/BattleCombat.lua` / `AttributeDef.lua`）

### 3.1 流程
- 按 `atkProgress += dt/interval` 累积普攻；战斗速度按钮循环 **1.0 / 1.5 / 2.0**。
- 目标选择：敌方**威胁加权随机**（ThreatManager）；治疗目标选**血量百分比最低**；多目标攻击的额外目标取仇恨最高。
- 胜利 = 敌人全灭；失败 = 己方全灭，1.5s 后**自动撤退到上一关**（无任何惩罚），无独立重试按钮。
- **首通限时 300 秒**，超时判负"时间到!"；挂机（非首通）无限时。

### 3.2 伤害管线（按序）
命中判定 → 基础攻击 × atkCoeff → 增伤（全局 + 物/魔分系加算）→ 暴击（默认暴伤 200%）→ 破甲（有效护甲=max(0,armor−pen)，溢出护甲转为额外穿透加成）→ 连击段数 → 伤害浮动 → 连击增伤 → 暴击倍率 → **类型克制倍率** → ×(1−抗性) → 圣物加成 → 格挡 → 向下取整（保底 1）。

- 命中率 = `(命中值+150)/(闪避值+150)`。
- 抗性 = `0.01×armor / (0.01×armor+1)`。
- 格挡：概率可超 100%（必格 + 余数概率）；默认减伤 60%，上限 80%；多次格挡乘法叠加。
- 连击：≥100% 必出 + 余数概率；额外一段延迟 0.1s 到达。
- 治疗独立公式：治疗量 × atkCoeff × (1+治疗加成) × |克制倍率| × 治疗暴击；**过量治疗**部分触发圣物回调（如艾尔温转为能量护盾）。

### 3.3 类型克制矩阵（攻击类型 × 护甲类型）

行=攻击类型（其归属：斩击/粉碎/穿刺=物理，火焰/冰霜/闪电/暗影=魔法，神圣=治疗），列=皮甲/轻甲/重甲/板甲/布甲：

| | 皮甲 | 轻甲 | 重甲 | 板甲 | 布甲 |
|---|---|---|---|---|---|
| 斩击 | 1.10 | 0.85 | 0.95 | 0.70 | 1.50 |
| 粉碎 | 1.20 | 1.10 | 0.75 | 0.60 | 1.40 |
| 穿刺 | 0.90 | 1.20 | 1.10 | 0.85 | 1.60 |
| 火焰 | 1.15 | 1.10 | 1.25 | 1.40 | 0.75 |
| 冰霜 | 1.05 | 1.00 | 1.15 | 1.30 | 0.80 |
| 闪电 | 1.30 | 1.25 | 1.50 | 1.65 | 0.65 |
| 暗影 | 1.00 | 0.95 | 1.05 | 1.10 | 0.90 |
| 神圣 | 治疗 | 治疗 | 治疗 | 治疗 | 治疗 |

### 3.4 六围派生（AttributeDef META / DERIVATIVES）
例：STR 每点 +1 物攻 / +0.5% 物伤 / +1 护甲 / +5 HP；LUK 每点 +0.3% 暴击率 / +1.5% 暴伤。完整派生表见 `systems/AttributeDef.lua`。

### 3.5 防磨血狂暴（StageBerserk）
- 120s：敌方攻速 +50%，己方攻击 +30%；
- 210s：敌方攻速 +100%、敌方攻击 +30%。

## 6. 挂机与离线收益（`systems/OfflineCalc.lua` / `config/IdleIncomeConfig.lua`）

- **击杀率**：每 3 秒 1 只（在线/离线一致）；**上限 12 小时**，不足 1 分钟无收益。
- 公式：`金币/经验 = 该关每分钟收益 × 分钟数`；英雄经验 = 玩家经验 × 出战人数倍率。
- 收益锚 = 最高首通进度（进行中取上一关）；掉落锚可不同。
- **额外 +2 小时**：看广告或消耗 1 特权点领取，**每日 3 次**。
- **关卡扫荡券**：1 券 = 10 分钟挂机收益（金币+双倍经验）+ 固定 10 件装备 + 10 卷轴，覆盖最高进度前 5 关。

## 7. 装备系统（`config/EquipmentConfig.lua` / `systems/EquipmentSystem.lua` / `BlacksmithConfig.lua`）

- **槽位**：主手 / 副手 / 护甲 / 饰品。模板 198 件（武器 72 / 副手 30 / 护甲 60 / 饰品 36）。
- **品质**（词缀数 / 基础强度）：普通 0/1.0 → 优质 1/1.1 → 稀有 1/1.2 → 史诗 2/1.3 → 传说 2/1.4 → 至臻 2/1.5；每强化级 +5% 数值。
- **强化 = 槽位强化**（不随装备更换丢失）：上限 `min(100, 远征等级)`；消耗金币 + 对应槽位卷轴（Lv1 ≈ 100 金+2 卷 → Lv100 ≈ 21.3 亿金+200 卷）。仅已上阵角色的出战位可强化。
- **词条**：44 条普通词缀 + 13 条魔化词缀（腐化石相关）；词缀品质 D/C/B/A/S（权重 100/80/60/40/20），数值随品质与等级缩放。
- **洗练**（铁匠铺）：消耗精粹；锁定词条成本 ×1.5；洗练次数上限 20；双手武器消耗 ×2。
- **分解**：产出洗练石 / 精粹（按品质 decBase 5–30 × 等级系数）；支持一键分解与背包满自动分解弹窗。
- **背包上限 200 件**；战利品箱（LootBox）只存"装备种子"，**开箱时才掷属性**。

## 9. 遗物 · 封兽祭阵（重点系统；`systems/RelicAltar.lua` / `server/relic/RelicService.lua` / `systems/RelicConditionHandler.lua`）

入口：城镇 → **亡誓公会** → 遗物标签（新手引导组 14，首通 1305 后触发）。

### 9.1 遗物本体（`data/RelicDefs.lua`）
- 5 种兽型：岩龟 / 毒蛇 / 白鹿 / 灰狼 / 猎鹰；6 品质（基础强度 12→45.7）；**满级 5**。
- **升级**：消耗奥术粉尘 `floor(基础 × (1+(level−1)×0.55))`，基础 20/40/80/200/480/960。
- **合成**：3 件**同型同品质**未锁定 → +1 品质（至臻不可再合）；等级取三件最高；可指定保留词缀（须为三件之一且新品质下有文本），否则随机重 roll。
- **重铸**：消耗粉尘（稀有 40 / 史诗 200 / 传说 1200 / 至臻 2400；普通/优质不可洗练）；先出预览再确认。
- **锁定**：锁定后不可参与合成。

### 9.3 阵法效果（仅本位，且成阵后生效）

| 阵 | 效果 |
|---|---|
| 龟阵 | 开战骑士/战士仇恨 +180×系数；物理/魔法格挡概率 +8×系数 |
| 蛇阵 | 刺客/法师造成伤害 30% 不增加仇恨 |
| 鹿阵 | 牧师过量治疗 40×系数 转为目标护盾 |
| 狼阵 | 战士/射手攻速 +8×系数；攻击回血 +12×系数 |
| 鹰阵 | 斩杀线 (12+品质×0.8)%，触发概率 0.45（对刺客/射手） |

**对位**：鹰+龟=天地（伤害+6%、生命+6%，受击递减的开场减伤，上限 30%）；蛇+狼=阴阳（输出不抢嘲讽）；鹿+阵眼=生门（治疗加成+10%，过量治疗 25% 平摊全队护盾）。
**邻接**：龟+鹿=守生（骑士/牧师生命+8%）；狼+鹰=攻天（战士/射手攻速+8%）；蛇+鹰=阴天（刺客暴击率+6%）；蛇+鹿=阴生（法师魔伤+8%）。
**大成**：五兽齐聚 → 免死一次（受致命伤留 1 血）；**圆满**：开战全队护盾 = 最大生命 ×8%。
