# 《终焉之门·单机版》玩法文档（按当前实现）

> 基线：`scripts/` 当前代码。本文只描述**当前实现**，不记录历史改动。
> 各节标注主要数据来源文件，便于维护时核对。数值一律以代码为准。

## 0. 游戏概览

- **类型**：横屏三栏放置型卡牌 RPG，暗黑魔塔画风（近黑暖底 / 铁灰 / 骨白 / 血红-余烬点缀）。
- **运行形态**：单机（`multiplayer.enabled=false`）。入口 `scripts/main.lua` → `boot/Standalone.lua`；规则层 `rules/` 经 `runtime/LocalActionBridge.lua` 本地直调；存档单文件 `standalone_save.json`。
- **战斗形态**：全自动放置，三行并行。无手动操作、无主动技能、无战斗倍速；英雄按各自攻击间隔自动普攻，天赋全部为被动/概率触发。无编队的行完全不显示敌人。
- **核心循环**：推关 → 击杀掉落 + 挂机收益 → 装备 / 神器 / 天赋 / 转职 / 觉醒养成 → 推更高难度 → 终焉神殿 → 轮回。

### 术语对照

玩家可见文案统一走「远征」世界观，内部键名（`adventurer` / `recruitTicket` / `playerLevel`）不变。

| 旧称 | 现称 | 说明 |
|------|------|------|
| 冒险等级 | **远征等级** | 玩家等级；槽位/队伍/强化上限都绑它 |
| 冒险经验 | **远征经验** | 玩家升级经验 |
| 冒险家 | **远征队员** | 英雄单位的玩家可见称呼 |
| 冒险招募券 | **远征招募券** | 酒馆常规池抽卡券 |
| 冒险日志 | **远征日志** | 日志页标题（日志页本身已删除） |
| 冒险奖励 | **远征奖励** | 奖励弹窗标题 |

## 1. 界面导航（横屏三栏）

数据来源：`boot/StandaloneHorizon.lua`、`core/Viewport.lua`、`ui/hud/TopBar.lua`、`ui/hud/BottomNav.lua`。

- **三栏布局**：base 1920×1080，左/中/右各 486 宽无缝拼接（设计稿 1080×2400 按 `DS=0.45` 缩入）。
  - 左栏 = 城镇及二级页（教堂/古树/酒馆/市场/铁匠铺/仓库/遗匣/功绩）。
  - 中栏 = 主视图（主线三行战斗 / 副本 / 通天塔）+ 全屏战斗页 + 全局弹窗层。
  - 右栏 = 角色页常驻（编队 / 名册 / 详情 / 配装 / 转职）。
- **顶部栏**：头像（打开玩家信息面板，内含设置）、昵称 / 远征等级 / 经验条、战力（余烬火焰图标）、金币、钻石。
- **底部导航**：`BottomNav` 为纯状态模块（页码 / 锁定 / 角标），不绘制任何视觉。
- **奖励弹窗跟随面板**：记录触发时所在栏（左/中/右），在该栏绘制并接收该栏输入；任意点击（含面板外）即关闭。内容超高时自动滚动到底，大数字徽章字号自适应。
- **全局层**：奖励弹窗、升级弹窗、离线收益、玩家信息。

## 2. 战斗系统

数据来源：`systems/CombatFormula.lua`、`ui/battle/combat/`、`systems/AttributeDef.lua`、`ui/battle/stage/StageBerserk.lua`、`systems/BattleTimeout.lua`、`systems/BossAffixSystem.lua`。

### 2.1 流程

- 普攻累积：`atkProgress += dt/interval`，≥1.0 触发攻击并减去 1.0；实际间隔 = `基础间隔 / (1 + 攻速%/100)`。每帧攻击次数有上限。
- **无战斗倍速**：战斗恒用真实 `dt`，没有 1x/2x/3x 档位。
- 目标选择：敌方**威胁加权随机**（ThreatManager）；治疗目标选**血量百分比最低**；多目标攻击的额外目标取仇恨最高。
- 胜利 = 场上敌人全灭且队列为空；失败 = 己方全灭，自动撤退到上一关（无惩罚），无独立重试按钮。
- **首通限时 300 秒**（`GameConfig.Battle.TIME_LIMIT_SEC`），仅首通生效，超时判负；挂机（非首通）无限时。终焉神殿不限时。

### 2.2 伤害管线（按序）

命中判定 → 基础攻击 × atkCoeff → 增伤（全局 + 物/魔分系加算）→ 暴击（默认暴伤 200%）→ 破甲（有效护甲 = max(0, armor − pen)，溢出护甲转为额外穿透加成）→ 连击段数 → 伤害浮动 → 连击增伤 → 暴击倍率 → **类型克制倍率** → ×(1−抗性) → 圣物加成 → 格挡 → 向下取整（保底 1）。

- 命中率 = `(命中值+150)/(闪避值+150)`。
- 抗性 = `0.01×armor / (0.01×armor+1)`。
- 格挡：概率可超 100%（必格 + 余数概率）；默认减伤 60%，上限 80%；多次格挡乘法叠加。
- 连击：≥100% 必出 + 余数概率；额外一段延迟 0.1s 到达。
- 治疗独立公式：治疗量 × atkCoeff × (1+治疗加成) × |克制倍率| × 治疗暴击；**过量治疗**部分触发相关回调。

### 2.3 类型克制矩阵（攻击类型 × 护甲类型）

行 = 攻击类型（斩击/粉碎/穿刺=物理，火焰/冰霜/闪电/暗影=魔法，神圣=治疗），列 = 皮甲/轻甲/重甲/板甲/布甲：

| | 皮甲 | 轻甲 | 重甲 | 板甲 | 布甲 |
|---|---|---|---|---|---|
| 斩击 | 1.10 | 0.85 | 0.95 | 0.70 | 1.50 |
| 粉碎 | 1.20 | 1.10 | 0.75 | 0.60 | 1.40 |
| 穿刺 | 0.90 | 1.20 | 1.10 | 0.85 | 1.60 |
| 火焰 | 1.15 | 1.10 | 1.25 | 1.40 | 0.75 |
| 冰霜 | 1.05 | 1.00 | 1.15 | 1.30 | 0.80 |
| 闪电 | 1.30 | 1.25 | 1.50 | 1.65 | 0.65 |
| 暗影 | 1.00 | 0.95 | 1.05 | 1.10 | 0.90 |
| 神圣 | 治疗 | 治疗 | 治疗 | 治疗 | 治疗 |

### 2.4 六围派生

例：STR 每点 +1 物攻 / +0.5% 物伤 / +1 护甲 / +5 HP；LUK 每点 +0.3% 暴击率 / +1.5% 暴伤。完整派生表见 `systems/AttributeDef.lua`。

### 2.5 护盾成长层

`AttributeDef.SHIELD_SCALING`（当前档：`hpRatio=8%`、`derivedLevelFactor=5%`）在 `UnitAttributes:recalc()` 末尾追加：护盾 += 最终 HP × 8% + 六围派生护盾 ×((1+(等级−1)×5%)−1)；无盾单位门控不加盾。详见 `docs/护盾成长层设计.md`。

### 2.6 狂暴与超时增伤

- **狂暴（StageBerserk，仅首通模式）**：一阶 120s（限时 40%）敌我攻速 +50%、己方攻击 +30%；二阶 210s（限时 70%）敌方攻速 +100% 且攻击 +30%、己方攻速 +100% 攻击 +30%。
- **超时增伤（BattleTimeout，全战斗通用）**：宽限 60s 后每 10s 双方伤害 +5%，上限 300%，经 `ctx.globalDmgMult` 注入，不影响治疗。

### 2.7 Boss 词缀（困难及以上章节 Boss）

仅困难及以上难度章节 Boss（每章第 5 关）首通生效。难度映射 tier（hard=1 … annihilation5=14），词缀数量 1/2/3。词缀池：

| 词缀 | 效果 |
|---|---|
| 守护之盾 | 开场获得护盾 |
| 强化体魄 | 最大生命提升 |
| 狂暴姿态 | 攻速提升（静态） |
| 暴怒 | 血量降到阈值时一次性触发攻速/伤害强化 |
| 生命汲取 | 每秒回血 |
| 荆棘之体 | 受击反弹伤害 |

按章节确定性取词缀（无随机），战斗实验室同样模拟。

## 3. 英雄与编队

数据来源：`config/HeroConfig.lua`、`config/ClassConfig.lua`、`config/ExpTable.lua`、`shared/heroes/TeamSlots.lua`。

- **品质**：普通（灰）/ 稀有（紫蓝）/ 史诗（金）/ 传说（橙红），共 **25 名**英雄（id 1–25 连续）。品质机制值 1–4。
- **碎片**：10 碎片合成解锁；抽到重复转碎片。
- **等级上限**：英雄 / 玩家均 200 级；支持经验溢出连升。
- **编队（三队并行）**：3 支队伍；队 1 开局解锁，队 2/队 3 分别通关普通 **9-5（905）/ 19-5（1905）** 解锁（`ExpTable.TEAM_UNLOCK_STAGES`）。每队最多 **4 槽**（左 4 角色 vs 右 4 敌人）；槽位按远征等级 Lv2 / Lv6 / Lv10 递增至 4。
- 出战人数经验倍率 1.0/1.5/2.0/2.5/3.0（`heroCountExpMult`）。
- 编队为拖拽上阵，跨队交换一次提交；同一 heroId 全局唯一（仅可存在于一队，队 1 优先）；队 1 与 `heroes.deployed` 双向镜像。

## 5. 挂机与离线收益

数据来源：`systems/OfflineCalc.lua`、`config/IdleIncomeConfig.lua`、`rules/offline/`、`config/DungeonIdleConfig.lua`。

- **击杀率**：每 3 秒 1 只（在线/离线一致），驱动装备/卷轴种子；金币与经验按分钟查表，不足 1 分钟无收益。
- **离线时长**：前 24 小时满额（`FULL_RATE_SECONDS=86400`），超出部分按 50%（`TAIL_RATIO=0.5`），**7 日硬顶**（`HARD_CAP_SECONDS=604800`，超出不产生收益与掉落）。
- 公式：金币/经验 = 该关每分钟收益 × 有效分钟数；英雄经验 = 玩家经验 × 出战人数倍率。
- 收益锚 = 最高首通进度（进行中取上一关）。每支已解锁非空队伍各自按保存关卡独立结算。
- **关卡扫荡券**：1 券 = 10 分钟挂机收益（`REWARD_MINUTES=10`）+ 固定装备与卷轴，只扫最高已通关。
- **副本挂机**：同 24h 软顶 + 7 日硬顶（`DungeonIdleConfig.FULL_RATE_SEC=86400` / `TAIL_RATIO=0.5` / `HARD_CAP_SEC=604800`）。

## 6. 装备系统

数据来源：`config/EquipmentConfig.lua`、`systems/EquipmentSystem.lua`、`config/EquipmentSetConfig.lua`、`config/BlacksmithConfig.lua`、`config/AffixConfig.lua`。

- **槽位（6 个）**：主手 `weapon` / 副手 `offhand` / 护甲 `armor` / 头盔 `helmet` / 鞋子 `shoes` / 饰品 `accessory`。ID 前缀 W/O/A/H/S/C。
- **模板约 358 件**（武器约 83 / 副手 38 / 护甲 66 / 头盔 66 / 鞋子 66 / 饰品 38），等级区间 1-16 / 17-32 / 33-48 / 49-64 / 65-80 / 81-9999。
- **品质**（词缀数 / 基础强度 / 词缀品质上限）：普通 0/1.0/— → 优质 1/1.1/2 → 稀有 1/1.2/3 → 史诗 2/1.3/3 → 传说 2/1.4/4 → 至臻 2/1.5/5。每强化级 +5% 数值（`LEVEL_SCALE=0.05`）。
- **等级门槛**：英雄等级 ≥ 装备等级才可穿（服务端权威校验）。
- **职业可穿戴**：武器/副手按英雄 `weaponTypes`/`offhandTypes`；护甲/头盔/鞋子按职业 `armorTypes`。
- **双持/双手**：双持天赋（转职 207 异类型 / 220 同类型）决定副手武器可放类型；无天赋不能把单手武器放副手槽。主手装双手自动卸副手；副手换装时若主手为双手则自动卸主手；双持天赋无法装常规副手。
- **套装（12 套）**：2 件纯属性、4/6 件战斗被动；4/6 件互斥（件数最多者，并列取 setId 字典序），两套 2 件可同时亮。双手武器无副手时 5 槽按 6 件计（`twoHandCountsAsSix`：叠甲虫壳、万剑门扉）。套装名称、归属与 2/4/6 件源文见 `docs/装备套装效果规划.md` 与 `EquipmentSetConfig.lua`。
- **强化 = 槽位强化**（不随装备更换丢失）：上限 `min(100, 远征等级)`；消耗金币 + 对应槽位卷轴。仅已上阵角色的出战位可强化。
- **词条**：45 条普通词缀（id 1–45，品质 D/C/B/A/S，权重 100/80/60/40/20）+ 13 条魔化词缀（id 1001–1013，最终 X 加成）。
- **升阶**：上限 `min(远征等级, 100)`；消耗 = 强化表 ×0.6。每 5 阶得 1 条随机普通词条，普通词条上限 4 条；满员后每里程碑栏位倍率 `affixMult` +0.10。固定副词条每阶按模板顺序轮转 +基础值 5%。
- **洗练**：精粹单价 = `refBase×(1+lv×0.05)`（品质 1–6 的 refBase 10/20/30/40/50/60），双手 ×2；锁定词条成本按条数阶梯累乘（1/2/3 条 = ×1.5 / ×2.25 / ×3.375）；洗练次数上限 20（仅计数）；腐化后精粹 ×2。
  - 洗练石：保留词缀种类，重 roll 品质与数值，保底只升不降。
  - 点金石：品质 +1（消耗 = 当前品质个数）；达进度上限后转为随机一条普通词缀品级 +1（最高 S）。
  - 腐化石：一条普通词缀转同类型魔化词条（数值 ×1.8）并叠一层诅咒；层数上限 3，每层基础属性 ×0.90。
  - 神圣石：逐层洗除诅咒，魔化词条保留。
- **分解**：精粹 = `decBase×(1+lv×0.1)`（品质 1–6 的 decBase 5/10/15/20/25/30）；洗练精粹返还 50%；升阶卷轴返还 70%。已穿戴或锁定装备不可分解。自动分解按品质与等级两维同时满足才执行。
- **背包上限 200 件**；遗匣保管超出背包的奖励，入匣即生成完整装备，支持稀有度与套装筛选。

- **16 种神器**：影羽斗篷 / 星辉护符 / 生命棱镜 / 命运纺锤 / 巨人之铠 / 神圣十架 / 左誓战旗 / 右誓法典 / 血誓圣杯 / 亡魂之祭 / 嘲讽面具 / 神徒之骰 / 狂怒沙漏 / 审判官之锤 / 魔王之瞳 / 双生壁垒。部分类型有最低品质限制。
- **装配**：每支队伍各自维护一套装配表；教堂神器页以三行同时显示（队1/2/3 各一行），队 2/3 按远征等级 10/20 解锁（未解锁行置灰）。每队 **4 个出战位置**，每个位置 **2 个神器子格**；第 1/2 格分别于远征等级 **30/60** 解锁。同一实例可同时装到多支队伍，但同队内只能装一次；同一位置内不能装相同类型。存档标识 `id` 是实例 ID，`artifactId` 才是类型 ID。
- **养成**：合成消耗 3 件同类型同品质的未装配神器 → 1 件更高品质同类型（至臻不可合成）；置换消耗 2 件同品质未装配神器 → 1 件同品质不同类型（排除输入类型）；洗练消耗 1 特权点，重新随机全部数值（结果可能变低）。
- **战斗接入**：`ArtifactBridge.applyToUnit(attrs, partySlot, data, teamIdx)` 挂载被动与运行时效果；`teamIdx` 缺省 1，`getDeployedTeam(teamIdx)` 按本队装配表构建；每队战力缓存按本队神器计算。`ArtifactRuntime` 处理闪避衰减、护盾破裂仇恨、反击、复活/亡魂、审判叠层等。
