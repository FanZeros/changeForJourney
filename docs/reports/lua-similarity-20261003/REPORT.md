## 5. 工具算法与统计局限

1. **读取与规范化**：文本按 UTF-8 解码；CRLF 和 CR 统一为 LF；不能解码的字节用替代字符；Lua 字节码跳过。行级比较去掉每行尾部空白，不去注释、不替换变量名、不做 AST 或 token 分析。
2. **同路径相似度**：只比较同一相对路径的两份文件，用 `difflib.SequenceMatcher(..., autojunk=False).ratio()`，记作 `s`。配对权重为 `max(镜像行数, 本地行数, 1)`，再求加权平均。去空行指标按非空行重新比较与加权。
3. **全量双向指标**：每侧文件行数乘以其同路径相似度，未配对路径按 0 计；两侧估算匹配行数之和除以两侧总可读行数，形成 `symmetric_dice`。这不是标准 token 集合 Dice，也不是实际相同行数精确计数。
4. **完整文本相同**：先统一换行，再以 SHA-256 判断；这里没有去尾空格、去注释或去空行。跨路径整文件哈希匹配只进入 `exact_line_pct_*`，**不会提高同路径覆盖率或双向相似度**。
5. **路径重构影响**：搬移、改名、模块拆分、模块合并可能使实际相关代码被统计为两侧独有路径；例如镜像 `ui/RewardPopup.lua` 与本地 `ui/hud/popup/RewardPopup.lua`，工具不自动比较。
6. **缺失文件影响**：《灰界》只读取到 48 / 241 个 Lua，193 个缺失清单项包括 `LuaScripts/` 71 项、`urhox-libs/` 112 项、`Validate/` 7 项及根目录库文件 3 项，不能统称为业务源码缺失；唯一同路径配对为 `main.lua`。缺失项不参与可读行数总量，路径集合仍含缺失条目，路径重合的分母与内容分母不完全一致。原报告的 `only_published` 不等于仅“已读取且本地缺少”的文件名单。缺失内容未知，不能确定它们对完整相似度的净影响方向。
7. **口径包含测试和配置**：本地含测试、工具与配置，配置格式化、注释、空白和大量新增测试都可能影响结果；镜像 manifest 也可能带入示例或工具路径。不能据文件数量直接推断玩法规模。
8. **结果不具法律定性**：相似代码可能源于同项目历史版本、授权复用或公共模式。报告只提供技术比较结果，不能据此判定抄袭、侵权或代码作者归属。
