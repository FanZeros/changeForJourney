## 2. 画风与画幅：沿用战斗画法，换成剧情机位

### 2.1 统一视觉

| 项目 | 规划要求 |
|---|---|
| 轮廓 | 近景清晰重黑墨线，远景降低线密度，不把所有层次同等描粗 |
| 色面 | 连续基础色＋少量宽大暗面，石头／木头只留必要结构接缝 |
| 黑色 | 门洞、柱背、梁底、低前景剪影使用近黑；地面与主地标保留中间调 |
| 光源 | 每幅一处柔和主光源，局部照明不过曝，不堆多色法术光 |
| 洁净度 | 无碎色斑、纸纹噪点、胶片颗粒、密集裂缝、漂浮粒子和镜头光晕 |
| 地域差异 | 由主轮廓和材质区分：门厅木梁、礼拜堂石拱、酒馆吧台、巨木空腔、荒漠遗骨 |
| 分层 | 纯背景不烘焙角色、怪物、NPC、奖励装备、文字、UI、边框或可读告示 |

书斋的桌案、帽子、印鉴、合上的名册是叙事环境道具；正文及翻阅／封缄提示由现有界面层负责，不画进背景。来信流程虽有sealed状态，当前没有独立绘制“终”字火漆印章；背景也不预先烘焙该字样。

### 2.2 剧情背景规格

- 标准候选：**1920×1080、16:9、不透明PNG**。需要2K绘制细节时可使用2560×1440后等比导出。
- 当前部分情景仍借用1080×2400竖图；放到1920×1080的cover里只保留约25.3%的源图高度。战斗1896×720图直接cover到剧情画布则只保留约67.5%的源图宽度。这两种旧资源都应先重构画幅，不能仅改资源路径就认为构图合格。
- 不能把战斗用1896×720图横向／纵向拉成16:9。以同地域战斗背景作参考，重新补足天空、室内顶部与景深，保留环境辨识点。
- 主程序当前固定**1920×1080逻辑画布**，窗口变化时整幅等比居中，非16:9窗口可能留边；不是随窗口比例重新裁成另一套构图。large在该逻辑画布内对源图片做cover，所以源图本身必须按16:9设计。未来独立使用播放器时仍应检查其它比例。
- 场景地标优先放在**横向55%—70%、纵向25%—58%**；中央约70%的画幅保留完整结构，左右各约10%留裁切余量。
- 当前人物大约以x=30%为中心。**左侧约15%—48%**保持低细节、低对比；不在角色头后画灯、尖塔尖或高亮窗格。
- 对话条顶部约在70%高度，底部又叠暗罩。**下方30%**只留连贯地面／简单家具暗面，不放关键线索、脸或文字。
- 书斋例外：现有信笺约占左70%宽度，采用“左边平静墙面，右边桌案”的构图；长译文可能扩展双栏，所以桌案不是必须一直可见的操作线索。
- 先检查整张纯场景，再叠真实人物、对话条、名字牌和继续提示。单图好看不等于游戏内合格。

## 4. 资产清单与每张场景提示词

### 4.1 共同前缀、共同结尾

BG01—BG19最终生成时组合：**共同前缀＋对应场景段＋共同结尾**。BG01使用其书斋专用构图，覆盖共同前缀中的普通对话构图段。**BG20使用完整独立模板，只继承画法与清洁要求，不组合下方共同前缀／结尾中的地面、人物覆盖区和偏右地标要求。**

共同前缀：

```text
《终焉之门》横屏剧情纯场景背景，不是角色海报或UI底板。
1920×1080、16:9、不透明画幅，平视或轻微低机位，中等景深。
沿用参考图的清晰重黑墨线、少量大块近黑背光和简洁连续色面，
参考图只锁定画法与黑色力度，不复制其中的水岸、树木、柱廊或石棺。
左侧15%—48%为角色立绘覆盖区，保持低细节、低对比；
下方30%为对白覆盖区，只留连贯地面，核心地标放在横向55%—70%的中远景。
中央约70%保留完整主景，左右和顶部留裁切余量。
```

共同结尾：

```text
地面用一块连续基础色和一两块宽大暗面表达，建筑或岩石只留必要结构接缝。
黑色用于轮廓、背光与门洞，不给整图叠黑滤镜；主要地形仍清晰可辨。
clean, smooth, even surfaces, uncluttered composition, restrained shading, controlled lighting。
不画斑驳碎色、细碎笔触、密集裂纹、颗粒、纸张噪点、漂浮粒子或镜头光晕。
不添加人物、动物、怪物、完整Boss、人形剪影、文字、水印、可读符文、UI、边框。
场景是环境，不把角色本体、怪物形象或可点击按钮烘焙进去。
```

## 5. 叙事连续性与现有实现限制

### 5.1 small不是“加一个background就能出图”

当前 `ScenarioDialogue.show` 仅在large加载`config.background`，small将背景句柄设为-1，并叠压暗罩。以下两种后续路线需明确选择，不能同时含糊实施：

1. **兼容优先**：small保持当前宿主页，无独立剧情场景；BG05等P1只作未来备用。
2. **场景化展示**：仍保留small的对白表现和业务门控，但增加显式“叙事底景”层及场景上下文，让小剧情在正确地点呈现。不要通过全量改large绕过现有背景接口，也不要换掉宿主页真实UI。

本规划默认先走兼容优先。要落实所有small的独立底景，需要用户确认下一阶段演出方式后再接入。

### 5.2 延迟补播必须记录剧情起源，不看当前打开的页

## 6. 制作顺序与验收

### 推荐顺序

1. **三张风格／构图试点**：BG01书斋、BG09幽烬求救商道、BG14终焉封门，分别验证室内交接、野外救援、终焉压迫。
2. 试点通过后补齐其余6张P0：BG02、03、04、10、15、16。
3. 再确认small是否场景化；确认后才做8张P1，不先批量烧素材预算。
4. BG18／19作为同机位色调变体；BG20及旧CG重做独立确认，不能顺手生成视频。
5. 已审核纯环境后，才接入播放层和对应路径；不改台词、奖励、角色表与原触发门禁。

### 每张验收

- 确认实际PNG尺寸与1920×1080请求一致，不把错误画幅强行拉伸。
- 同时看无遮挡原图与真实剧情叠层，至少覆盖16:9、16:10、4:3、窄横屏。
- 左侧人物与下方对白不遮核心地标，名字牌、步骤计数、继续提示仍清楚。
- 黑色用于形体和背光，不能二次压暗导致整景糊黑；small原罩与自带暗图叠加应单独检查。
- 地点与当前剧情起源一致；遇真假角色不切错相对章节。
- 字体、翻译、关键词与奖励弹窗继续沿现有逻辑，不把文字烘焙进图。
- 同背景三英雄分支、切句、关闭重开、轮回回退、旧档补播均无空图或错图。
- 新图赋独立meta；样稿和下载包不进正式包；官方Build后按manifest确认实际资源与路径。
- 规划完成不等于素材完成；构建成功不等于所有设备的视觉和交互已验收。
