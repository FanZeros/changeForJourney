## 八、避雷清单（血泪）

1. **协作会话活跃**：另一个 agent 会往 feat/main 推提交（一天多次）。**任何 push 前必须先 fetch**；发现新提交先读 `docs/COLLABORATION.md` 与其提交信息。
2. **dist 层（assets/ + 1.0.x manifest）只准 CRC32 管线生成**，禁止手工直改——上次直改被要求 revert（9f78bd4）。
3. manifest 是**紧凑单行 JSON**，`json.dumps(d, ensure_ascii=False)` 序列化可字节级复现，勿 pretty-print。
4. `/workspace/assets` 的 `.meta` 文件承载 uuid，**替换图片时绝不能动 .meta**。
5. `git add` 只用显式路径；`assets-restored/`（506M）与 `__pycache__/` 严禁入库。
6. GitHub Release 资产名中文会被洗掉 → 用 ASCII 名 `SuMingLvTu-Win64-Offline.zip`。
7. GitHub Pages/Fastly 缓存 max-age=600，推完等 1-2 分钟再验（查询参数不参与缓存键）。
8. 用户 PAT 曾在会话中明文出现过（ghp_0awS...），**提醒用户撤销**；后续 push 若无凭证需用户重新提供。
9. 图片替换后若游戏内立绘空白/拉伸异常：先查 KP_GW 尺寸（应 512×1024）与 .meta 是否被误删。
