## 构图铁律

先锁原图，再改地貌。原图是 1896×720（约 2.63:1）满幅线稿林，左右大树框景，枝条交错到顶，地面是树根夹着的小路。

| 必须 | 禁止 |
|---|---|
| 用 `L1_row1_forest.png` 做 edit 母图，锁构图和密度 | 从零生成空地、远山、大月亮 |
| 画布 1896×720。工具常返回 1896×1264，居中偏下裁回 720 | 3:2、16:9 空景，或把两侧拉宽 |
| 地貌写进树缝和地面：沙、雪、晶、水只在原有结构里替换 | 各章都是「上半天空 + 下半平地」 |
| 中央留一条被树根/石根夹着的路，脚落在下半 | 把地平线画成一条空线 |

70%–90% 只说明卡牌脚落在画面下段，不要为此把上半画成天空。横条规格 1896×720。工具返回 1896×1264 时，居中偏下裁回 720，不要按地平线百分比硬裁。
