### 2.1 老六（R 换面人）

- **梗**：游戏「老六」= 蹲人、偷袭、不正面。避开真人。
- **和谁错位**：小雀是开场点名+受伤+25%；内鬼是暴击面板+偷攻速。老六走 **仇恨诡计**：前期没有铁憨憨时，靠 0 仇恨活过第一波。
- **天赋「蹲人」**：开战 4 秒内攻击不产生仇恨；第一次攻击必定暴击，并额外复制目标护甲克制 +0.05（叠在职业「换面」+0.1 上，上限写死，避免爆表）。
- **配队**：前期 叮咚鸡 + 老六 + 大狗嚼；中期给内鬼让位，老六去 2/3 队。
- **不要**：再给暴击率（内鬼已经占了）；不要隐身模型（放置没手动）。

### 2.2 电子木鱼（R 司仪）

- **梗**：功德+1 / 电子木鱼。治愈但不碰「改死亡」（死亡归职业延缓）。
- **和谁错位**：卡皮巴拉是 HoT；复活吧爱人是队友首死 25% 复活；真布诗人是溢治疗转盾。木鱼走 **减伤buff**，三人奶不抢机制。
- **天赋「功德+1」**：每次成功治疗功德 +1（自己身上，最多 5）。满 5 清空，给治疗目标 3 秒「清心」：受伤 −18%。一场战斗可多次。
- **配队**：前期唯一 R 奶，和老六/叮咚鸡组成能过引导的最小队。
- **不要**：复活、免死、延缓（和司仪职业撞）。

### 2.3 加载中（SSR 封门人）

- **梗**：转圈加载 / 请稍候。伤害先缓存再吐出，和门缝「伤害进队列」同一语言，但英雄天赋做 **受击反吐**，职业做 **持续释放**。
- **和谁错位**：接化发是格挡回血+挡下的伤害加到自己下一击；铁憨憨是 HP+20%、仇恨×1.5、给队友分摊 15%。加载中不奶自己、不分摊，专吃「我挨打→条满→砸回去」。
- **天赋「缓冲圈」**：受到的伤害 25% 写入加载条（独立于门缝，容量=最大生命 10%）。条满或 6 秒未写入时，对当前目标打出条内全部粉碎伤害，并按写出量产仇恨。
- **配队**：中后期 加载中 + 弱网战士（封门给回响+15%）+ 司仪；铁憨憨去二队。两人坦可以三队并行各带一个。
- **不要**：再分摊、再改死亡、再给格挡（接化发的活）。

### 2.4 弱网战士（UR 回响客）

- **梗**：高延迟 / 999ms / 弱网战士。职业回响已经是「1.2 秒后第二击」；英雄把 **第一击也延迟**，专门吃裂痕、感电、潮湿。
- **和谁错位**：叮咚鸡是第三下必暴；信光机兵是蓄满打群体 70%；弹弹弹是弹射。弱网是 **单目标延迟爆头**。
- **天赋「高延迟」**：普攻伤害推迟 1.5 秒结算。结算时若目标当前生命百分比低于出手时，本次延迟伤害 +35%（乘法）。延迟伤害走回响同一套仇恨（固定 10%），避免抢坦。
- **配队**：标准后期核：加载中（封门+15% 回响）+ 弱网 + 阿姨压/蓝色大肥鱼（感电/受潮）+ 真布诗人。裂隙使的裂痕也会让延迟结算更痛。
- **不要**：再弹射、再 AOE（信光已经占了）；UR 进星辉池，不进常规券池。
