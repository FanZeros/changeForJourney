## 一、设计语言总纲（所有素材统一遵循）

### 1.1 色板（core/DarkIcon.lua · Palette 单一来源）

| 角色 | 色值 | 用途 |
|---|---|---|
| 近黑暖底 | `#0D0B09` | 画布/画廊底 |
| 主体深 | `#1C1712 → #100D09` 垂直渐变 | 面板/按钮主体 |
| 标题带 | `#241E17 → #17120D` | 弹窗标题区 |
| 铁灰系 | `#96866F / #60564A / #2E2A24` | 金属高光/中间调/暗部 |
| 骨白 | `#D8C9A3`（发丝线用 α0.08） | 内衬、文字主色 |
| 琥珀金 | `#C9973B`（亮 #F0C75E / 暗 #6E4E18） | 饰线、货币、高亮 |
| 血红 | `#A61E1E`（亮 #E04848 / 暗 #6E1010） | 宝石、危险语义 |
| 余烬橙 | `#FF7A28` | 火焰、红点辉光、进度填充 |
| 语义色 | 绿 `#5F9E3E` · 蓝 `#3E7EC2` · 紫 `#8A4EC2` · 血钻红 `#C43A1E` | 品质/按钮语义 |

### 1.2 三条铁律

1. **粗描边，不靠光影**：图标与部件用纯黑 α1.0 卡通描边（宽度 ≈ 尺寸×0.03）定轮廓；渐变只做扁平材质（金属/宝石切面/火焰），禁用柔光晕染（P0 二轮已确立，战斗双剑风格为基准）
2. **中心点定位 + alpha 全链路透传**：与原 `drawImageCentered` 调用习惯对齐，迁移零心智成本
3. **切片布局神圣不可侵犯**：凡涉及贴图九宫格的替换/重绘，边框带布局必须与原图逐像素对齐（详见 §4 约束）

### 1.3 文字规范（既有 DrawUtil 延续）

标题/数值：骨白或琥珀金 + 黑描边（drawTextStroke 既有能力，不改）。

## 四、Track B · 矢量九宫格面板体系（P1 主战场）

### 4.1 现状关键约束

- `drawNineSlice` 全项目 **159 处**调用，15 个模块本地复制实现
- 切片参数按原图像素硬编码（弹窗底顶带 180、背包大面板顶带 400）
- **矢量方案天然免疫该约束**：不切片、任意拉伸，只需目标矩形

### 4.2 API 设计（core/DarkIcon.lua）

```lua
--- 暗黑矢量面板（中心化绘制体系，替代贴图九宫格）
---@param style string
---   "panel" 弹窗底（暗铁标题带 + 金饰线 + 深底主体，对应 UI_TY_EJQRK）
---   "plain" 纯底板（对应 UI_*BJ 局部底）
---   "btn"   按钮条（铁灰底 + 语义色描边，对应 UI_AN_*）
---   "slot"  凹槽（进度条/滑条底槽）
---   "fill"  进度填充（余烬渐变，配 slot 使用）
---@param x y w h  目标矩形（左上角定位，与 drawNineSlice 同参风格）
---@param opts table|nil {
---   accent = "gold"|"green"|"blue"|"red"|"purple"|{r,g,b},  -- 语义色
---   titleH = number,   -- panel 标题带高，默认 h*0.17（clamp 70..190）
---   studs  = boolean,  -- panel 金线端点菱形装饰，默认 true
---   radius = number,   -- 圆角覆盖（默认按 min(w,h) 推导）
---   alpha  = number,   -- 默认 1
---}
function DarkIcon.drawNine(vg, style, x, y, w, h, opts) end
```

### 4.3 样式结构

```
panel（r≈min(w,h)*0.046，对齐原图 950×648 → r30）
┌──────────────────────────────────────────┐ ← 黑描边 α0.6
│ ██ 标题带 #241E17→#17120D ██             │
├───◆────────────────────────────◆─────────┤ ← 金饰线 #C9973B + 端点菱形
│  主体 #1C1712→#100D09                    │
│  内衬骨白发丝 α0.08                       │
└──────────────────────────────────────────┘   顶缘高光 #96866F α0.5

btn：铁灰 #2A241D→#1A1510，r=h*0.3，语义色 2px 描边 + 顶缘 α0.35 内高光
slot：#100D09 凹槽 + 内阴影顶线；fill：余烬 #FFB43C→#E85D1A + 顶部光泽线
plain：同 panel 去标题带（保留发丝内衬与描边）
```

### 4.4 迁移机制（针对 159 处调用）

1. **本地复制体模块（15 个）**：删除本地 `drawNineSlice` 函数，替换为薄适配壳（保持调用行参数不动）或直接改调用行
2. **调用行替换**：`drawNineSlice(vg, imgBg, x, y, w, h, IT,IR,IB,IL)` → `DarkIcon.drawNine(vg, "panel", x, y, w, h)`，同时删除对应 `nvgCreateImage`（省显存）
3. `DrawUtil.drawNineSlice` 保留，服务剩余低频贴图
4. 每迁移一个模块：截图对比 + validate

### 4.5 迁移顺序（引用热度）

AnnouncementPanel(28 引用家族) ✅（d861ad9）→ MailPanel → ArenaLogDialog → ArenaShopPage → BackpackPanel(400 带大面板) → ArtifactDetailPanel → ArenaPage/ArenaRankRewardDialog → 其余。

### 4.6 画廊验收

`DarkIcon.drawShowcase` 已加"矢量九宫格"区块：panel/plain/btn(金绿红)/slot+fill 实样，与贴图版并行对照（`SHOWCASE = true` 开启）。

## 六、风险

- **panel 标题带与模块自绘标题文字的相对位置**：迁移时以模块现有 TITLE 常量校准 titleH，不强行统一
- 半透明遮罩（MASK_A=128）叠暗底后视觉变重 → 迁移时逐页检查遮罩 α
- 长期目标：ui/ 模块对 `image/UI_*BJ` 家族的依赖逐步归零，新增面板一律 drawNine
