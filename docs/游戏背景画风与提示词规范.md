# 《终焉之门》游戏背景画风与提示词规范

> 2026-10-03，经用户多轮看图确认的制作规范。
> 适用于关卡与副本的纯场景背景，不适用于角色立绘、觉醒CG或UI底板。
> 核心方向：**重黑墨线、简洁色面、少量大块阴影、明确环境差异**。

## 1. 已确认的视觉标准

本轮选择过程：三种画风对照 → 选择墨线手绘 → 加重黑色视觉 → 减少杂色色块 → 确认简洁色面版本。

| 项目 | 应当保留 | 应当避免 |
|---|---|---|
| 轮廓 | 景物主轮廓清晰，近景适量粗黑线 | 所有远景都同等粗描边，密集细线 |
| 黑色 | 背光面、洞口、前景剪影上的大片近黑 | 整张叠黑滤镜，地面和主景糊成黑块 |
| 色面 | 连续基础色，少量宽大的明暗块 | 斑驳小色片、碎笔触、相近颜色频繁跳变 |
| 纹理 | 少数必要接缝和形体转折 | 胶片颗粒、纸张噪点、密集裂纹、随机暗纹 |
| 光源 | 一个柔和、明确的主光源 | 多色光混杂、满屏亮点和镜头光晕 |
| 构图 | 一个核心地标，完整战斗地面，前后层次 | 画成独立海报，背景抢卡牌，所有环境套森林隧道 |

**“干净”不是把图模糊，也不是消灭所有阴影。**用户认可的是减少细碎杂色，仍保留轮廓、体积和少量大阴影。

### 黑色视觉如何加重

优先加强：
- 石碑、柱侧、岩壁的背光面；
- 洞口和壁龛内部；
- 低矮前景的剪影；
- 主要景物轮廓。

同时保留沙地、雪面、石台的中间调。场景可以幽暗，但必须看得出地形。雪地不应全黑，晶洞不应满屏霓虹，矿洞不应满洞金光。

## 2. GPT Clean 的使用逻辑

本轮明确使用 `model="gpt"`，并按 `gpt-image-clean-prompt` 规范组织提示词。这个参数指定GPT生图路线，**不能据此宣称某个未返回的具体后端型号**。

优先靠正向构图与元素限制控制画面：
1. 明确这是游戏纯场景背景；
2. 每张只描述一个主要地标及少量辅助物；
3. 写明卡牌叠加空间、完整战斗地面和景深；
4. 指定已确认的统一画法；
5. 指定唯一主光源；
6. 加一段短清洁约束；
7. 最后排除人物、文字、UI等不应烘焙的内容。

不要把“古老、神秘、魔法、极高细节、厚重纹理”等词连续堆叠。它们容易诱发无意义符文、脏纹和光点。

### 推荐清洁词块

按场景选用，不需要每次把所有排除词写满：

```text
clean, smooth, even surfaces, uncluttered composition,
restrained shading, controlled lighting,
no mottled patches, no grain, no particles
```

中文要落到具体表面，而不是只写“干净”：

```text
地面以一块连续基础色和一两块宽大暗面表达。
云层合并为两三层连贯大形。
岩石与石柱只保留必要结构接缝。
不画斑驳小色片、碎笔触、密集裂纹或漂浮粒子。
```

“一两块暗面”“两三层云”是控制视觉复杂度的目标，不是机械的像素数量验收。

### 主光源示例

| 场景 | 唯一主光源 |
|---|---|
| 林道、沼泽、雪岭、露天遗迹 | 阴云下柔和漫射天光 |
| 沙丘、湖畔 | 地平线的克制暮光 |
| 幽烬林地、焦土、烛龙巢 | 一处余火或远处热光 |
| 血晶溶洞 | 主晶簇内部一处暗红光 |
| 墓室、矿洞 | 一盏固定暖灯 |
| 上古遗迹、亡灵墓穴 | 一处克制苍青或冷绿光 |

光是局部照明，不是粒子素材。除非用户另行要求，不添加火星、飘雪、尘埃、闪光点或魔法光束。

## 3. 参考图如何使用

### 新场景生成

使用一张已审核的正式背景锁画法，例如：
- `assets/image/战斗背景/哑雾沼泽.png`：简洁地面、克制云层与近黑前景；
- `assets/image/战斗背景/古代遗迹.png`：建筑体积与结构线；
- `assets/image/战斗背景/遗忘墓穴.png`：室内大阴影与暖灯。

提示词必须明确：

```text
参考图只锁定画法与黑色力度，不复制其中的水岸、树木、柱廊或石棺。
```

不要用旧森林图强锁沙漠、雪山的构图；否则即使改了地名，也可能仍然生成枯树夹道。

### 清理已有场景

参考顺序：
1. 第一张：要保留布局的原场景；
2. 第二张：已审核的简洁色面风格参考。

```text
保持第一张的机位、主要景物位置和配色。
第二张只提供简洁色面处理，不复制第二张的景物。
```

批量生成后必须逐张看图，文件名不能替代内容审核。

### 未来关联剧情CG

先生成并审核纯场景，再以该场景为第一参考图，角色官方立绘为后续参考图。保持地点、机位、光源与布局，只新增角色和动作；不要把场景与角色一起凭空重设计。

## 4. 可直接复用的提示词模板

### 新建横版关卡背景

```text
《终焉之门》卡牌战斗纯场景背景：【地名】。
参考图只锁定画法：清晰黑色轮廓、少量大块近黑阴影、平整简洁色面，
不复制参考图中的【需排除的原场景景物】。
1896×720超宽横向画幅。
前中景是【完整、宽阔的战斗地面】，后方【一个核心地标与少量辅助物】。
主景完整置于中央80%范围，上下留裁切余量，左右卡牌覆盖区低细节、低对比。
配色为【基础色、阴影色、局部点缀】，地面保留可辨中间调。
唯一主光源为【一处柔和光源】。
地面一块基础色加一两块宽大暗面，景物只留必要结构线。
clean, smooth, even surfaces, uncluttered composition, restrained shading。
不画斑驳碎色、密集纹理、颗粒或漂浮粒子。
不添加人物、怪物、文字、符号、UI或边框。
```

### 杂色色块清理

```text
修改第一张游戏背景，保留原构图、景物位置、黑色力度和配色。
第二张仅锁定已审核的简洁色面，不复制景物。
保留清晰黑色轮廓与少量大块阴影。
地面合并为连续基础色和一两块宽大暗面；
天空使用两三层连贯大云形；水面只保留少量宽缓反射。
移除斑驳小色片、尖角碎片、碎笔触和细小亮斑。
景物仍有体积，不模糊全图，不继续整体压黑，不新增道具。
clean, smooth, even surfaces, restrained shading,
no mottled patches, no grain, no particles。
不添加人物、文字、符号、UI或边框。
```

### 竖版副本背景

在新建模板中将构图段替换为：

```text
1080×2400竖版游戏背景，非海报。
上半部完整显示【岩顶或建筑结构】，中段后方设置【核心地标】；
前方与下半部保留大片连续平缓地面供战斗卡牌覆盖。
主要道具放在远景和两侧，不把关键物体放在卡组背后。
```

## 6. 规格、导出与游戏内验收

| 用途 | 当前成品尺寸 | 资源路径 |
|---|---|---|
| 主线23章L1 | 1896×720，不透明PNG | 第一章 `image/暗黑/L1_row1_forest.png`，其余 `image/战斗背景/地名.png` |
| 三行终焉/塔 | 1896×720，不透明PNG | `image/战斗背景/终焉神殿.png`、`通天塔.png` |
| 矿洞/遗迹挑战 | 1080×2400，不透明PNG | `image/关卡地图/MAP_FB1.png`、`MAP_FB2.png` |

注意事项：
- `aspect_ratio` 与 `target_size` 是请求，不是结果保证。本轮曾请求1896×720却返回1896×1264；必须打开图片核验实际尺寸。
- 主线背景绘制按1896×720固定计算cover；石框可见窗口不等于原图，第三行裁切与前两行不同。主景放中央约80%、顶部预留约10%是美术安全建议，不代替实机检查。
- 错画幅优先重新构图，保留完整瀑布、峰顶和建筑；只有不损失关键主景时才裁切。不要把竖图直接拉成横图。
- 矿洞/遗迹虽然显示框为1080×2400，当前平台压缩流程对长边超过2048可能报超限。原始PNG入包成功不等于各平台压缩通过；正式发布须核对目标平台产物，必要时等比降低导出分辨率并重新验收。
- 普通副本现有 `DarkIcon.drawDarkScene` 会乘暗色并叠晕影。新图自身已暗时可能二次发黑；先看游戏内效果，不擅自改全局压暗规则。
- 同名替换保留原 `.meta`；新独立背景使用新资源ID。
- 样稿与下载包不覆盖正式文件，也不混入发布包。入包排除以实际manifest检查为准。
- 替换后必须官方Build，检查资源路径、产物内容，完全重启预览以清除路径缓存。

### 每张验收清单

- [ ] 场景内容和文件名一致，地形区别于相邻章。
- [ ] 实际尺寸正确，主景完整，没有拉伸与黑边。
- [ ] 地面连续可站立，卡牌后方低细节、低对比。
- [ ] 黑色用于轮廓和背光，地面仍有中间调。
- [ ] 无细碎杂色色片、颗粒、随机暗纹或多余粒子。
- [ ] 唯一主光源明确，晶体和灯光不过亮。
- [ ] 无人物、完整Boss、文字、水印、符号、UI或边框。
- [ ] 游戏内叠卡、血条、特效、石框裁切与锁定行均清楚。
- [ ] 场景切换与返回主线背景正确，不因共享句柄失效出现空图。

逻辑测试、构建成功和图片单独看起来漂亮，都不能替代真实游戏视觉验收。
