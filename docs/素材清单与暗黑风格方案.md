## 一、项目概况

| 项 | 值 |
|---|---|
| 引擎 | UrhoX（NanoVG 全量自绘 UI，无原生 UI 控件） |
| 入口 | `scripts/main.lua` → 单机模式路由到 `network/Standalone.lua`（multiplayer.enabled=false） |
| 设计分辨率 | 1080×2400 竖屏（Mode A），UI 模块统一 draw/open/isOpen 协议 |
| 源码规模 | 301 个 Lua 模块（scripts-src → 已复制到 /workspace/scripts） |
| 资源总量 | 1099 个文件（哈希名，已按 manifest 还原为逻辑路径 → /workspace/assets） |

### 资源映射机制（重要）

- `1.0.1/manifest-origin.json` 记录 `fs_path`（逻辑路径，如 `image/装备图标/UI_icon_ZB_W1.png`）→ 构建哈希文件名（如 `A08jIZJBczYtZj9QFokYSbXC-96bce82a.png`）。
- 代码中 `nvgCreateImage(vg, "image/xxx.png", 0)` 按逻辑路径加载，构建时自动重定向。
- ⚠️ 构建产物里的 `.png` 大多实际是 **KTX 压缩纹理**（构建时转换），原始 PNG 不在仓库中。

## 五、DarkIcon 使用方式

```lua
local DarkIcon = require("core.DarkIcon")

-- 通用图标（中心点 + 尺寸）
DarkIcon.draw(vg, "gold",  cx, cy, size, alpha)
DarkIcon.draw(vg, "gem",   cx, cy, size, alpha)
DarkIcon.draw(vg, "power", cx, cy, size, alpha)
DarkIcon.draw(vg, "nav_battle", cx, cy, size, alpha)   -- nav_hero/nav_log/nav_battle/nav_town/nav_dungeon

-- 装备品质框（1-6 品，暗黑金属边框）
DarkIcon.drawQualityFrame(vg, quality, cx, cy, w, h, alpha)

-- 画廊验收页（临时钩子在 Standalone.draw，验收后置 false）
DarkIcon.SHOWCASE = true
```
