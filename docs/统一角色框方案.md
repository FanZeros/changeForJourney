# 统一角色框（HeroFrame）

> 组件：`scripts/ui/widget/HeroFrame.lua`。全游戏角色头像 / 卡牌框体统一走此组件。

## 1. 设计基准

- **视觉基准**：矢量品质色描边框（纯矢量，零新增贴图）。
- **品质映射**：英雄品质 1~4 用专属色，色源唯一为 `HeroConfig.QUALITY_INFO`（`HeroFrame.qualityColor` 运行时换算）。装备品质框（ZBBJ 体系，1~6）独立，不复用英雄品质色。
- **统一金色**：框体非品质元素用 `GOLD = (212,175,90)`，选中/拖拽高亮 `GOLD_HI = (255,214,102)`。

## 2. 品质色

| 品质 | 机制值 | 颜色 |
|---|---|---|
| 普通 | 1 | `a0a0a0` |
| 稀有 | 2 | `a2a0ff` |
| 史诗 | 3 | `ffed00` |
| 传说 | 4 | `ff6a00` |

## 3. API

| 函数 | 说明 |
|---|---|
| `M.initImages(vg)` | 加载组件所需贴图（幂等） |
| `M.getImages()` | 取已加载贴图表 |
| `M.qualityColor(quality)` | 品质 → RGB（色源 `HeroConfig.QUALITY_INFO`） |
| `M.draw(vg, opts)` | 绘制头像框；`opts` 含 `heroId`/`x`/`y`/`w`/`h`/`quality`/`selected`/`dragging`/`hover`/`frameOnly`/`borderOverride`/`lockOverlay`/`teamTag` 等 |
| `M.hitTest(px, py, cx, cy, w, h)` | 命中检测 |

## 4. 绘制内容

- 品质色描边（`borderOverride` 可覆盖）。
- 等级 / 职业图标 / 碎片 / 队伍角标（按框尺寸等比化）。
- 交互态：选中、拖拽、悬停。
- `frameOnly` 只画框不画内容；`lockOverlay` 画锁定遮罩。

## 5. 接入范围

编队头像、英雄名册、头像选择、角色详情卡、已装备角标、战斗结算、伤害统计、奖励、离线、指定招募、招募卡、背包碎片、顶栏、玩家信息、剧情对话、教堂、铁匠铺、觉醒面板等界面统一接入。
