# 统一角色框方案（feat926/unified-character-frame）

> 目标：全游戏所有"英雄/角色头像与卡牌"的框体统一为一套矢量组件 `ui/widget/HeroFrame.lua`，
> 消灭当前 13 种并存风格、3 套品质色表、6 种金色色值、3 种品质→框映射。
>
> 已确认决策（2026-09-27，用户选定）：
> 1. **视觉基准**：矢量品质色描边框（以编队头像框 `CharacterPanelDraw2.drawAvatarSlot` 为基底升级，纯矢量零新增贴图）
> 2. **接入范围**：P1+P2+P3 全套（20+ 处全部统一）
> 3. **品质映射**：英雄品质(1~4)用专属色（`HeroConfig.QUALITY_INFO` 为唯一色源），不复用装备 ZBBJ 贴图框(1~6)；装备品质框体系保持不动

| # | 问题 | 证据位置 |

## 二、HeroFrame 组件设计

新文件：`scripts/ui/widget/HeroFrame.lua`（与 ImageCache / QualityMark 同级）

### 2.1 品质色（唯一色源）

```lua
HeroFrame.QUALITY_COLORS = {
    [1] = {160,160,160},  -- 普通  a0a0a0（来自 HeroConfig.QUALITY_INFO，RGB 化）
    [2] = {162,160,255},  -- 稀有  a2a0ff
    [3] = {255,237,  0},  -- 史诗  ffed00
    [4] = {255,106,  0},  -- 传说  ff6a00
}
-- 运行时直接 require HeroConfig.getQualityColorRGB 换算，本表仅做缓存与文档化
```

统一金色（框体非品质元素）：`GOLD = (212,175,90)`（编队现行值），高亮 `GOLD_HI = (255,214,102)`。

### 2.2 API

```lua
HeroFrame.draw(vg, opts)  -- 一站式
-- opts 字段（全部可选，缺省即最小框）:
--   必给: cx, cy, size（正方形边长；卡牌模式给 w/h）
--   heroId            有则自动取头像(HeroAssetUtil.ensureIcon 按需缓存)与品质
--   w, h              卡牌模式（默认 = size,size）
--   radius            圆角，默认 size*0.08（148→约12，176→14，与现行一致）
--   mode              "icon"(头像方框) | "card"(整卡)  默认 icon
--   state             "owned"|"unowned"|"empty"|"locked" 默认按 heroId/owned 推断
--   quality           覆盖品质（不传则查 HeroConfig）
--   showName          框下方名字（带描边，20px@148 等比）
--   showLevel  level  左下等级徽章（贴图 lvlBadge 回退矢量黑圆，尺寸 = size*0.30）
--   showClass         右下职业图标（尺寸 = size*0.30）
--   showShards shards 未拥有：底部碎片进度条（含"可合成"提示）
--   showTeamTag teamTag 左上队伍归属标签
--   showUpgrade       右上可提升角标（iconUp）
--   selected          金色高亮描边（+4px 外扩，stroke5）
--   dragSource        拖拽源半透明 0.45 + 金高亮
--   hoverTarget       绿色放置提示 (99,255,132)
--   dimmed            未拥有压暗 0.45（现行 roster 行为）
--   alpha             整体透明度
--   posLabel          顶部站位名（编队"前锋/中锋/中卫/后卫"）
--   iconHandle        直接传已加载句柄（跳过内部缓存，兼容各面板自有 cache）

HeroFrame.hitTest(x, y, cx, cy, w, h)  -- 复用 DrawUtil.hitTest
HeroFrame.qualityColor(quality)        -- 返回 r,g,b（唯一映射入口）
```

### 2.3 绘制规格（视觉基准 = 现行编队头像框，升级点标注 ✨）

```
┌─────────────────────────────┐
│ ①底：圆角矩形 (20,16,12,255) │  空位 (0,0,0,60)/锁定 (0,0,0,90)
│ ②头像：scissor 圆角裁剪 cover │  未拥有 alpha 0.45
│ ③✨品质描边：QUALITY_COLORS[q] │  stroke = max(2, size*0.02)；
│    owned alpha 230/未拥有 90   │  ✨替代现行统一金边 (212,175,90)
│ ④等级徽章(左下) + 职业图标(右下)│  尺寸等比 size*0.30
│ ⑤碎片条(未拥有,底部内嵌)        │
│ ⑥队伍标签(左上) / 可提升(右上)  │
│ ⑦selected/drag/hover 交互态    │  统一金 (255,214,102) / 绿 (99,255,132)
└─────────────────────────────┘
```

贴图资源（沿用现有，不新增）：`lvlBadge=UI_JSJM_DJ.png`、`classIcons=ICON_ZY_1~6.png`、`iconUp=ICON_UP.png`、`shardSp=ICON_SP.png`、`lock=UI_ICON_SUO.png`、`plus=UI_ICON_JIA.png` —— 由 `HeroFrame.initImages(vg)` 统一加载一份，各面板逐步改为引用。

## 四、风险与对策

| 风险 | 对策 |
|------|------|
| 品质描边替代金边后，编队"选中/激活"识别度下降 | selected 态保留独立高亮金 (255,214,102)+5px，与品质边叠加 |
| card 模式各面板卡高不同 (350/438) | opts.w/h 显式传入，圆角与徽章按 h 等比 |
| RecruitAnim 动画中逐帧绘制性能 | HeroFrame 全矢量+按需贴图缓存，与现行 drawCardBg 同级开销；避免每帧 nvgCreateImage |
| 各面板自有 heroIconCache | opts.iconHandle 直通参数，兼容不强制迁移缓存 |
| 战斗内 BattleDraw 单位卡 | **本期不动**（战斗卡带血条/状态层，属战斗专属视觉，列入后续专项） |
