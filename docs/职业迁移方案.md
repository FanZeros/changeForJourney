# 职业体系迁移方案（研究稿）

> 状态：**仅规划，未改 ClassConfig / AdvancementConfig / 存档**。
> 日期：2026-09-22
> 分支：`docs/equip-set-and-class-migration`
> 目标：职业效果和设定与原版（骑士/战士/法师/射手/刺客/牧师 + 圣骑士/狂战士/魔导师……）**完全不同**；英雄梗人设保留。

---

## 0. 为什么要迁，而不是改名

原版职业是标准 MMO 六职：

| 原 ID | 现用中文名 | 实际机制（仍是原版） |
|-------|------------|----------------------|
| knight | 守誓者 | VIT+5，开场 20× 仇恨，板/重甲 |
| warrior | 破阵者 | STR+5，物伤 +10%，重甲 |
| mage | 咒术师 | INT+5，魔伤 +10%，布/轻 |
| ranger | 夜猎者 | AGI+5，文案远程、实现攻速 +10；有骑士/战士时仇恨 −80% |
| assassin | 无痕者 | LUK+5，暴击 +5%，皮甲 |
| priest | 提灯者 | SPI+5，治疗 +10%，布/皮 |

一转 12、二转 24 也全是原版分支（圣骑士/龙骑士/狂战士/决斗者/咒术师/魔导师……），只是基础职被换了暗黑称呼。

问题：

1. **名字暗黑了，效果没暗黑。** 玩家转职仍在点「圣光术 / 狂暴之血 / 奥术飞弹」。
2. **和英雄天赋抢戏。** 英雄已经是玩梗被动（衔骨、氮气、星门、抄作业）；职业还在给泛用 +10% 伤，职业没存在感。
3. **六职 = 六职能**（坦伤奶敏刺），放置编队 5 槽会被锁死成「1 坦 3 输出 1 奶」。终焉之门想要的是「门、债、回响、换面」，不是地下城职能表。
4. 存档里写的是 `classId` 字符串 + `advBranch` 数字（101–224）。**可以迁，但必须做映射表，不能直接删键。**

所以本文是「换骨架」，不是「再起六个暗黑别名」。

---

## 1. 新职业骨架：六条「门契」

不再按坦克/DPS/治疗分。按**和终焉之门的契约方式**分。战斗仍是全自动放置，职业只提供被动和资源规则。

| 新 ID（建议直接换字符串） | 中文 | 一句话 | 原职大致对位 | 护甲 |
|---------------------------|------|--------|--------------|------|
| `seal` | 封门人 | 把伤害封进门缝，延迟结算 | knight | 板/重 |
| `spoil` | 拾骸者 | 击杀与掉落转化为自身层数 | warrior | 重/轻 |
| `rift` | 裂隙使 | 改写克制与异常，不堆魔伤% | mage | 布/轻 |
| `echo` | 回响客 | 攻击留下延迟第二击 | ranger | 轻/皮 |
| `mask` | 换面人 | 偷敌人一条规则，而不是暴击 | assassin | 皮 |
| `debt` | 司仪 | 管理死亡与过量，不主加治疗% | priest | 布/皮 |

**基础六围加成全部取消 +5 主属性。** 改成「契约资源」：每条职业有一种只在战斗中存在的层数/债/回响，出战斗清零。避免又变成 STR+5。

威胁（仇恨）仍需要，否则放置 AI 没坦克。但仇恨不再是骑士专属天赋，而是封门人的**副产品**（封进去的伤害转化成门压，门压=仇恨）。

## 2. 六职效果（与原版对照，禁止照搬）

每条都写：原版做了什么、新版做什么、不要做什么。

### 2.1 封门人 `seal` ← 守誓者/骑士

| | 原版 | 新版 |
|--|------|------|
| 面板 | VIT+5 | 无面板。开场获得「门缝」容量 = 最大生命 12% |
| 被动 | 第一次攻击 20× 仇恨 | 自身受到的伤害先写入门缝（最多容量）。门缝每秒释放 20%。释放时 30% 打给当前目标（物理），70% 仍打自己 |
| 仇恨 | 高基础仇恨 | 写入门缝的量 × 系数转为仇恨（打人的那 30% 也产仇恨） |
| 护甲 | 板/重 | 仍板/重（克制矩阵不用推翻） |

不要：圣光、嘲讽喊话、龙血回血。那些是一转原版。

**为什么不同**：坦克从「我很肉 + 我很恨」变成「伤害进队列」。会和格挡、叠甲套互动（先进门缝还是先格挡 —— 建议 **先格挡，再进门缝**）。

### 2.2 拾骸者 `spoil` ← 破阵者/战士

| | 原版 | 新版 |
|--|------|------|
| 面板 | STR+5，物伤 +10% | 无。击杀（或助攻）获得 1 骸骨，最多 12 |
| 被动 | 纯增伤 | 每骸骨：攻速 +1.2%，移动的是攻击进度。满 12 时下次攻击消耗 6 骨，额外打一次 40% 伤害 |
| 护甲 | 重甲（配置里写了两次重甲） | 重/轻，让部分梗战士能穿轻甲鞋攻速 |

不要：狂暴低血增伤、嗜血自残。英雄里熬夜冠军、叠甲怪已经占了「低血/叠层」。

**为什么不同**：职业强度来自**战斗节奏中的击杀数**，短战斗弱、刷怪关强，和关卡长度挂钩。

### 2.3 裂隙使 `rift` ← 咒术师/法师

| | 原版 | 新版 |
|--|------|------|
| 面板 | INT+5，魔伤 +10% | 无。每 8 秒展开 4 秒「裂隙」 |
| 被动 | 泛魔伤 | 裂隙期间：本角色攻击的克制系数向 1.25 拉近（弱克变强、强克略收），并对目标施加 1 层裂痕（与套装晶蚀分开） |
| 护甲 | 布/轻 | 仍布/轻 |

不要：奥术飞弹、易伤诅咒（这俩是一转核心，迁一转时也要换掉）。

**为什么不同**：法师不再是「智力C」。职业在打**克制矩阵**，和装备甲种、怪物护甲互动。火法打布甲的 0.75 克制能被裂隙拉起来，这是原版职业完全没有的事。

### 2.4 回响客 `echo` ← 夜猎者/射手

| | 原版 | 新版 |
|--|------|------|
| 面板 | AGI+5，实现是攻速 +10 | 无。每次普攻在目标身上留 1 个回响（1.2 秒后打 45% 伤害） |
| 被动 | 有坦时仇恨 −80% | 回响**不吃仇恨公式**（固定 10% 仇恨）。有封门人在场时，回响伤害 +15%（替代「躲在坦后面」） |
| 护甲 | 轻/皮 | 仍轻/皮 |

不要：阵前提速、巡游射击那种「别人挨打我反击」——可放到一转，但基础职不要。

**为什么不同**：远程身份用「时间差第二击」表达，而不是攻速和减仇恨两个补丁。

### 2.5 换面人 `mask` ← 无痕者/刺客

| | 原版 | 新版 |
|--|------|------|
| 面板 | LUK+5，暴击 +5% | 无。战斗开始复制「当前目标的护甲类型克制」作为自己的攻击侧修正 +0.1（例如打板甲的穿刺更香） |
| 被动 | 纯暴击 | 目标死亡后，3 秒内换成下一个目标的甲种修正；期间下一次攻击附加「面」：无视 20% 护甲 |
| 护甲 | 皮 | 仍皮 |

不要：隐匿清仇恨、双持（双持留给二转且要换名字）。暴击是内鬼英雄的饭碗，职业不要再 +5%。

**为什么不同**：刺客从暴击职业变成**针对护甲类型的变形职业**，和裂隙使一个改克制、一个偷克制，编队可以同时带但效果不叠同一层（裂痕 ≠ 面）。

### 2.6 司仪 `debt` ← 提灯者/牧师

| | 原版 | 新版 |
|--|------|------|
| 面板 | SPI+5，治疗 +10% | 无。治疗量基础系数降到原 90%（职业不再靠治疗%） |
| 被动 | 疗愈 | 过量治疗转化为「延缓」：目标下次致死伤害可垫一次，垫掉的部分变成 4 秒债（受伤 +15%）。每人身上最多 1 层延缓 |
| 护甲 | 布/皮 | 仍布/皮 |

不要：团队治疗%、圣光术、复活（复活是英雄「复活吧爱人」的身份）。

**为什么不同**：奶妈从「抬血条」变成「管死亡」。和套装「终焉司仪袍」6 件致死改 1 血要分工：职业管「垫一次」，套装管「债爆发」。两者不要同时保留 6 件致死改写 —— 若套装采用该 6 件，职业 6 件冲突时套装改为护盾向。

## 3. 转职树重做（12+24 全部换设定）

数字 ID **建议保留 101–224**，只换 `name / talentId / talentDesc / statBonus`。这样旧存档 `first=105, second=211` 不会空指针，只会变成新效果。

若你坚持「连 ID 都要新的」，则必须做存档迁移函数（见 §5）。默认方案：**ID 不动，效果全换。**

### 3.1 一转（Lv10，1 万金）—— 每职 2 条，全部新机制

| ID | 新名字 | 基职 | 新天赋（草案） | 原版丢掉的 |
|----|--------|------|----------------|------------|
| 101 | 门闩 | seal | 门缝容量 +50%；释放伤害的 50% 改为打敌人 | 圣光术 |
| 102 | 闸门 | seal | 门缝满时强制嘲讽 2 秒，并清空 30% 门缝（打自己的那部分免了） | 龙之血 |
| 103 | 骨市 | spoil | 骸骨上限 12→18；消耗时回复 4% 已损失生命 | 狂暴之血 |
| 104 | 剥壳 | spoil | 对精英/Boss 击杀也给 3 骨；消耗攻击改为打护甲类型克制优势目标 | 战场决斗 |
| 105 | 错位 | rift | 裂隙冷却 8→6 秒；裂痕满 3 层时打一次 60% 魔攻 | 易伤诅咒 |
| 106 | 深缝 | rift | 裂隙期间自身攻击附加随机次类型（火/冰/雷/暗轮换） | 奥术飞弹 |
| 107 | 残响 | echo | 回响可暴击（主人暴击率 40%）；回响延迟 1.2→0.8 秒 | 巡游射击 |

### 3.2 二转（Lv25，10 万金）—— 只升级一转，不新开第三套职能

原版二转是「圣堂骑士 / 瘟疫巫师 / 鹰眼箭神……」一整本职业志。新版二转全部改成**把一转机制推到怪的程度**，名字走终焉梗。

命名原则：不出现 骑士/战士/法师/牧师/刺客/弓手 字样。

| 一转 | 二转 A | 二转 B |
|------|--------|--------|
| 101 门闩 | 201 封条（门缝释放改为 100% 打敌人，自己不挨） | 202 殉门（门缝爆炸时全队获得 3 秒 8% 减伤） |
| 102 闸门 | 203 死闸（嘲讽时门缝不打自己） | 204 反冲闸（嘲讽结束立刻填 40% 攻击进度） |
| 103 骨市 | 205 骨潮（消耗不花骨，改为每秒掉 1 骨，期间永久 40% 额外段） | 206 骨债（消耗时自损 3% 当前生命，额外段 80%） |
| 104 剥壳 | 207 双械（副手可装另一把武器，但骸骨获取 −30%） | 208 连剥（对同一目标连续攻击时骸骨获取 +1，换目标清） |
| 105 错位 | 209 群缝（裂痕同时上全体敌人，效果 70%） | 210 蚀缝（裂痕目标每次受伤额外 50% 魔攻暗影，1 秒 CD） |
| 106 深缝 | 211 择缝（轮换改为锁定克制最优的次类型） | 212 爆缝（次类型切换时对邻敌 100% 魔攻） |
| 107 残响 | 213 风回（回响命中给自己 12% 攻速 5 秒，最多 3 层） | 214 瞳回（回响必定暴击，叠暴伤层） |
| 108 叠声 | 215 瞄回（回响吃穿透；叠声第 2 击 + 穿透） | 216 重回（攻速锁 100%，多余攻速变回响系数） |
| 109 借面 | 217 静面（5 秒未挨打则「面」破甲 20%→40%） | 218 千面（5 秒未挨打则攻速 +40%，不再 +暴击） |
| 110 剥面 | 219 致命面（暴击时攻击进度 +100%，每轮 1 次 —— **仅当英雄本身会暴击时有意义，职业不加暴击**） | 220 双面（副手可装同类型武器） |
| 111 延祷 | 221 战祷（延缓触发后，该队友下次攻击 +25% 伤） | 222 血祷（延缓改为 40% 概率，但触发时按伤害回血） |
| 112 领忏 | 223 大赦（债结束治疗 ×3，低于 20% 生命必治疗暴击） | 224 罚忏（治疗时 40% 对随机敌打治疗量 300% 暗影） |

二转 A/B 仍是「同一转职两条里挑一条」。结构与现在 UI 一致，文案和 `talentId` 全换。

`talentId` 建议新前缀 `gate_201_seal_strip`，旧 `adv_201_advanced_holy` 留别名映射一版，防止热更中途报空。

英雄天赋、名字、梗 **全部保留**。只改他们的 `classId` 对位是否仍合理。

| id | 英雄 | 现职 | 建议新职 | 理由 |
|----|------|------|----------|------|

| 2 | 黄桃龙 | 法师 | rift | 燃烧 DOT，裂隙改克制 |
| 3 | 叮咚鸡 | 射手 | echo | 第三下暴击 vs 回响，错开 |

| 13 | 弹弹弹 | 射手 | echo | 弹射 vs 回响，弹射是空间、回响是时间 |
| 14 | 内鬼 | 刺客 | mask | 暴击斩杀；职业禁止再加暴击 |

武器类型表（`WEARABLE_DATA`）第一期 **不改**，避免铁匠/穿戴校验连锁。闪电卖鸡若改 echo，仍拿剑斧，允许「回响客用近战」——这正是和原版射手的差别。

## 5. 存档与代码迁移

### 5.1 字段

| 字段 | 现在 | 迁移 |
|------|------|------|
| `hero.classId` | `"knight"` 等 | 映射成 `"seal"` 等 |
| `advBranch.first/second` | 101–224 | **保留数字**，换配置内容 |
| 天赋运行时 `talentId` | `adv_101_holy_light` | 新 id + 旧 id 别名 |
| UI 职业名 | ClassConfig.name | 直接换 |
| 教堂/转职面板文案 | AdvancementConfig | 直接换 |
| 教程/对话里「骑士」 | DialogueConfig 等 | 全文检索替换，避免漏网 |

### 5.2 `classId` 映射表（写死，一次函数）

```
knight    → seal
warrior   → spoil
mage      → rift
ranger    → echo
assassin  → mask
priest    → debt
```

进游戏读档时若发现旧字符串，改写内存并标记 `dirty`，下次存盘覆盖。无需版本号 bump，但建议 `saveVersion += 1` 方便回滚。

### 5.3 必须改的文件（落地时）

```
scripts/config/ClassConfig.lua          -- 六职本体
scripts/config/AdvancementConfig.lua    -- 12+24 文案与属性
scripts/config/HeroConfig.lua           -- classId、闪电卖鸡对位
scripts/systems/TalentEffect.lua        -- 新旧 talentId 路由
scripts/systems/*Threat*                -- 骑士开场 20× 仇恨删除，改门压
UI 转职/详情/图鉴文案
docs/changeForJourney-gameplay.md       -- 玩法文档同步
```

**不要动**：装备模板数值、英雄天赋描述、掉落、神器、遗物。

### 5.4 风险

1. `TalentEffect` 里大量 `adv_10x_*` 分支，换 id 漏一条就是静默没效果。
2. 夜猎者「有坦减仇恨」被很多射手依赖；改回响后前中期射手会被打。应用封门人在场回响 +15% 补偿。
3. 武器大师/双刃（207/220）是装备规则不是战斗公式，迁名字时 **规则可保留**（双械/双面），这是少数允许「机制留下、设定换皮」的点。
4. 牧师治疗 −10% 基数会让早期关卡变劝退。应用「延缓」在新手关几乎不触发（没致死）来平衡，不要再暗补治疗%。
