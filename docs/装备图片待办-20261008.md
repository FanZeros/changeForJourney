## 5. 替换条件

1. 图必须是对应部位的独立物件：头盔/帽子不得以完整胸甲或全身铠甲代替；保持暗黑装备图的透明背景与风格。
2. 实际查看正式 PNG，并在装备槽、仓库/铁匠铺缩略展示中确认轮廓清楚、无错误部位、无边缘截断；文件存在或有效图片句柄不等于美术验收。
3. 旧 H13/H19/H25/H31 换成正确头盔后，移除对应旧六阶组的临时 `iconTemplateId`，恢复原组首 fallback；保留 ID/资源标识与数值。
4. 新 H62/H63 及其余新增防具独立 PNG 确认后，移除临时来源、恢复自身 ID 路径。
5. 同步更新本清单与 `scripts/tests/equipment_icon_fallback_test.lua` 的预期来源，再运行回归。
