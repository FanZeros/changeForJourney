# 装备套装效果

> 本文描述**当前**套装设计。权威源文与数值以 `scripts/config/EquipmentSetConfig.lua` 为准；
> 繁/英/日/韩译文在 `scripts/core/I18nEquipmentSets.lua`，与配置表逐字对应。

## 1. 规则总述

- **套装数量**：12 套（`ESC.SET_ORDER` 固定展示顺序）。
- **阈值**：2 件 / 4 件 / 6 件。2 件为纯属性加成；4 件、6 件为战斗被动。
- **互斥**：4/6 件效果互斥，按件数最多者生效，件数并列时取 setId 字典序；两套的 2 件效果可同时亮。
- **双手五算六**：`twoHandCountsAsSix` 套装（叠甲虫壳、万剑门扉）在主手为双手武器、副手为空、其余四槽同套时，5 件按 6 件计。
- **归属**：模板 `setId` 显式指定，或按名字规则 + 饰品表 + 副手类型兜底解析（见 `EquipmentSetConfig.resolve`）。
- **跨甲**：裂隙水晶不限护甲类型。

## 3. 归属与集齐

- 12 套均存在 81 级及以上的同等级可掉落 / 合法可穿 / 最高档可激活路径。
- 普通满套需要六个不同装备实例：主手、副手、护甲、头盔、鞋子、饰品。
- **万剑门扉**为纯双手五件路线（双手主手 + 其余四槽，副手为空，5 件计 6）；**叠甲虫壳**同时支持单手六件与双手五件路线。
- 新增候选会自然分摊同槽随机池概率；无定向掉落或短期集齐保底。
- 201 级及以上装备高于英雄 200 级上限仍不可穿（全局等级门槛）。

## 4. 显示

- 套装图标：`ui/widget/EquipmentSetIcon.lua` 程序化徽记；角色/仓库/工作台/遗匣/装备详情等界面以左下角标展示套装归属，可在设置中开关。
- 套装筛选：`ui/widget/SetFilterDialog.lua`，仓库装备页与遗匣共用。
