# 装备套装效果规划（研究稿）

> 状态：**P1 已落地（2 件纯属性）**。4/6 件战斗被动未做。
> 日期：2026-09-22
> 分支：`docs/equip-set-and-class-migration`
> 原则：不改现有掉落/强化/洗练闭环，套装是**额外一层激励**，不是第二套装备系统。
>
> **已拍板（2026-09-22）**
> 1. 首发 **8 套全做**
> 2. **允许跨甲**（裂隙水晶可跨甲种）
> 3. 双手武器满套按 **5 槽激活 6 件**（`twoHandCountsAsSix`）
> 4. **两套 2 件可以同时亮**；4/6 件仍互斥（件数最多，并列字典序）
> 5. **不要角色专属套**

---

## 0. 结论（先看这个）

当前装备是「槽位模板 + 品质词缀 + 槽位强化」，**没有任何套装字段**。6 槽已齐（主手 / 副手 / 护甲 / 头盔 / 鞋子 / 饰品），正好够做暗黑风 2/4/6 件套。

本规划建议：

1. **不新做一套独立装备表**。给现有模板打 `setId`，按命名系列归组（水晶、帝国、夜行、贤者……），再补 **4 套终焉主题命名套**（新名字、旧数值骨架）。
2. 件数阈值固定 **2 / 4 / 6**。双手武器占副手 → 满套按「已穿槽位数」算，不按模板件数。
3. 2 件给小属性；4 件给战斗被动；6 件给队伍级或机制改写。避免和职业被动、英雄天赋叠成「又一个 +10% 物伤」。
4. 套装效果走现成 `UnitAttributes.addModifier` + `TalentEffect` 同类钩子，不新开战斗公式。

下面 8 套是推荐首发名单。数值是**方向稿**，落地前要按战力表再压一轮。

## 1. 现状（代码已核实）

| 项 | 现状 |
|----|------|
| 槽位 | `weapon / offhand / armor / helmet / shoes / accessory`（6） |
| 模板 | 武器 72 / 副手 30 / 护甲 60 / 头盔 60 / 鞋子 60 / 饰品 36 ≈ 318 |
| 品质 | 普通→至臻 1–6，词缀 0–2 条 |
| 养成 | 槽位强化（不随换装丢失）+ 词缀洗练 |
| 套装 | **无** `setId` / `setBonus` / 套装 UI |
| 属性入口 | `EquipmentSystem` → `attrs:addModifier` |
| 战斗被动入口 | `TalentEffect` + 转职 `talentId` |

现有模板已经按**系列名**成组，这是天然套装种子，不必从零做 Unique：

| 系列痕迹 | 覆盖槽 | 备注 |
|----------|--------|------|
| 水晶* | 武器全系 + 部分副手 | 满级段 `{81,9999}`，适合当「毕业白板套」 |
| 帝国 / 圣骑士 / 审判官 / 元帅 | 板甲头胸鞋 | 守誓者向 |
| 夜行者 / 刺客 / 无踪 | 皮甲头胸鞋 | 无痕者向 |
| 巡林客 / 追猎者 / 神射手 | 皮甲+轻甲 | 夜猎者向 |
| 大贤者 / 奥术师 / 咒法师 | 布甲 | 咒术师向 |
| 光明圣 / 主教 / 微光者 | 布甲（护盾线） | 提灯者向 |
| 叠甲战神之剑 / 巨剑 | 仅武器 | 件数不够成套，建议扩到头胸鞋或并入「叠甲」主题套 |

**缺口**：饰品是戒指/项链/耳环散件，没有系列名；副手（盾/典/珠/杯）也几乎不跟胸甲同名。套装若要求 6 件，必须给饰品、副手补 `setId`，不能只靠名字匹配。

## 2. 设计约束（拍板口径）

### 2.1 计数规则

```
穿戴槽里 template.setId 相同的件数 = N
双手武器：主手计入，副手槽被占用但不计套装件（避免「一件顶两件」）
品质不管：普通水晶剑和至臻水晶剑都算同一套
强化等级不管：套装看「是不是这套」，强度仍由强化/词缀负责
```

建议阈值：

| 件数 | 定位 | 强度预算（相对单件白板） |
|------|------|--------------------------|
| 2 | 小属性，随时能凑 | 约 1 条 B 级词缀 |
| 4 | 个人战斗被动 | 约半个一转天赋 |
| 6 | 机制改写或小队光环 | 接近一个英雄小天赋，禁止超过核心天赋 |

**2 件可多套同时亮**（已拍板）。4/6 件仍互斥：只算件数最多的那套；并列取 `setId` 字典序。UI 配装顶栏显示 `套名 N/6`。

### 2.2 和现有系统的边界

| 系统 | 套装可以碰 | 套装不要碰 |
|------|------------|------------|
| 词缀 | 2 件给扁平属性 | 不要再 roll 额外词缀 |
| 转职 | 4 件可以「呼应」职业机制 | 不要复制一转/二转原文 |
| 英雄天赋 | 6 件可以放大触发条件 | 不要写死某个 heroId |
| 神器/遗物 | 无直接耦合 | 不要按神器类型激活套装 |
| 掉落 | 可给高难关「套装倾向」权重 | 不要做独立套装掉落表（第一期） |

### 2.3 获取方式（第一期）

- **打标签**：现有模板加 `setId`，玩家穿齐即亮。
- **不新做掉落池**。高阶关卡已经能掉对应等级段模板。
- 第二期再考虑：铁匠「套装共鸣」（同套 4 件以上，消耗奥术粉尘把散件转成同套）。

### 2.4 UI（第一期最小）

角色详情装备区：套装名 + `2/6` 进度；点开浮层显示 2/4/6 文案，已激活的高亮。
背包：同套装备小角标（色点即可，不必新图标）。
铁匠：强化界面只读提示「当前套装」，不参与强化消耗。

## 3. 推荐 8 套（首发）

命名走《终焉之门》暗黑梗，不走原版圣骑士/帝国腔。每套标注：主题、建议职业、建议绑定的现有模板、2/4/6 效果、为什么和原版装备「只加数值」不同。

件数标记：`H` 头盔 / `A` 护甲 / `S` 鞋子 / `W` 主手 / `O` 副手 / `C` 饰品。

---

### 套 1 · 叠甲虫壳 `set_carapace`

- **主题**：越挨打越厚，像叠甲怪本人的甲片外置。
- **适合**：守誓者、破阵者（板/重）。
- **绑定**：重甲/板甲头胸鞋 + 重盾 + 力量向戒指/项链。武器可用「叠甲战神之剑/巨剑」扩一组同 setId。
- **2 件**：生命 +6%，护甲 +4%。
- **4 件**：每次受击获得 1 层「甲片」（最多 8）。每层受伤 −1.5%（乘法外另算一层，和格挡分开）。
- **6 件**：甲片满层时，下一次攻击消耗全部层数，把层数×2% 转为本次伤害，并嘲讽当前目标 2 秒。
- **研究点**：和叠甲怪英雄天赋「每攻叠甲」会不会太像？若会，6 件改成「满层时分摊队友 8% 伤害」而不是再叠攻。

---

### 套 2 · 夜行无面 `set_faceless`

- **主题**：把脸藏进门缝，仇册与暴击。
- **适合**：无痕者、夜猎者（皮甲）。
- **绑定**：夜行者/刺客/无踪头胸鞋 + 细剑/匕首 + 轻盾或空副手 + 幸运向饰品。
- **2 件**：暴击率 +4%，闪避 +5%。
- **4 件**：对「当前生命低于 50%」的敌人暴伤 +25%。
- **6 件**：击杀后 4 秒进入「无面」：仇恨清零，下次攻击必定暴击且不产生仇恨。
- **研究点**：和内鬼「低血斩杀」、暗杀者一转「隐匿清仇恨」重叠。6 件可改成「无面期间普攻附加目标已损失生命 2%（有上限）」以拉开。

---

### 套 3 · 裂隙水晶 `set_riftcrystal`

- **主题**：满级段「水晶*」系列的正式身份——不是亮闪闪的毕业装，是门内结晶体。
- **适合**：全职业（跨甲种）。这是**唯一建议做成跨甲**的套，当通用毕业壳。
- **绑定**：所有名字含「水晶」的武器/副手 + 各甲种 81+ 段里挑 1 条改名或打同一 setId（不必真改名，第一期只打标签）。饰品「水晶之戒 / 水晶挂坠 / 水晶耳环」并入。
- **2 件**：全伤害 +4%，能量护盾 +8%。
- **4 件**：攻击命中时 15% 给目标 1 层「晶蚀」（最多 5）。每层该目标受到的元素（火/冰/雷/暗）伤害 +3%。
- **6 件**：晶蚀满 5 层时碎裂，造成一次魔法攻击 80% 的暗影伤害，并沉默攻击进度 0.6 秒（对 Boss 降为 0.2 秒）。
- **研究点**：跨甲满套是否让职业甲种限制变废？建议 6 件效果**不加成护甲类型克制**，只做异常，避免人人弃职业甲去堆水晶。

---

### 套 4 · 终焉司仪袍 `set_last_rite`

- **主题**：不是奶，是改写死亡。
- **适合**：提灯者（布甲护盾线：光明圣/主教/微光者）。
- **绑定**：布甲 B 线头胸鞋 + 权杖 + 圣杯 + 治疗向耳环。
- **2 件**：治疗加成 +8%，护盾 +6%。
- **4 件**：过量治疗的 20% 转为能量护盾（和真布诗人天赋分流：套装只转 20% 且不可再溢出成临时盾）。
- **6 件**：小队任一成员将受到致死伤害时，改为保留 1 点生命并获得 3 秒「终焉债」（受伤 +30%）。每场战斗每名成员限 1 次。
- **研究点**：和复活吧爱人 25% 复活、圣骑士圣光术抢节奏。6 件应做成「债」而不是复活，避免双复活。

---

### 套 5 · 高压水脉 `set_tidepress`

- **主题**：潮、溅射、降温。给蓝色大肥鱼和冰系一个可凑的壳，而不是角色专属套。
- **适合**：咒术师（布/轻）、带冰霜/闪电主类型的英雄。
- **绑定**：布甲 A 线（贤者袍）+ 法杖/魔杖 + 法珠 + 魔力向饰品。可把「雪皇/肥鱼」常用模板打标，不写死 heroId。
- **2 件**：魔法穿透 +6%，攻击间隔视觉不变、实际 atkSpeed +5%。
- **4 件**：攻击主目标时 30% 溅射邻近 1 人，伤害 35%（和肥鱼天赋溅射加算前先分开发：套装溅射不带「受潮」）。
- **6 件**：被套装溅射命中的目标 3 秒内攻击进度 −20%。对已受潮/冻结目标改为 −35%。
- **研究点**：和雪皇冰冻、阿姨压感电是否该互斥。建议套装只减速进度条，不上新异常名，减少状态栏爆炸。

---

### 套 6 · 赛道硝烟 `set_nitros`

- **主题**：加速、贯穿、命中换触发。闪电卖鸡的氮气哲学外置。
- **适合**：破阵者、夜猎者（轻甲/重甲攻速鞋线）。
- **绑定**：轻甲或重甲「勇士/勇者/战争」头胸鞋 + 单手剑/细剑/手铳 + 轻盾 + 命中向饰品。
- **2 件**：攻速 +8%，命中 +6。
- **4 件**：每 80 点命中值，连击率 +2%（最多 +10%）。
- **6 件**：连击触发时，额外一段改为「贯穿」：对仇恨第二的目标打 50% 伤害。若场上只剩 1 个敌人，改为自身攻速 +12%，持续 2 秒（不叠层）。
- **研究点**：和信光机兵「第 4 下贯穿」、卖鸡氮气贯穿叠乘。6 件贯穿系数要低于英雄天赋。

---

### 套 7 · 万剑门扉 `set_swordgate`

- **主题**：飞剑、额外弹道、低仇恨。万剑归宗的「剑不是人打的」。
- **适合**：破阵者（双手剑/双手斧）。双手占副手 → **满套按 5 件槽就激活 6 件效果**（特例，文档里写死）。
- **绑定**：双手剑/斧高阶 + 重甲头胸鞋 + 物穿向饰品。无副手。
- **2 件**：物理穿透 +8%，物伤 +5%。
- **4 件**：每 6 秒召唤 1 柄门缝飞剑，打随机敌人，伤害 = 这 6 秒内自身造成伤害的 15%，仇恨 10%。
- **6 件（5 槽特例）**：飞剑数量 +1；飞剑可以暴击（用主人暴击率的 50%）。
- **研究点**：和 UR 万剑归宗 5 秒 3–6 剑严重撞车。二选一：① 此套禁止万剑归宗穿（UI 提示「剑已过多」）；② 套装飞剑改为「队友共享」光环，本人不触发。推荐 ②，让套装给小队物理 C 用，而不是给本人再飞一轮。

---

### 套 8 · 无光星图 `set_starless`

- **主题**：不发光的星门残骸。摘星星星人哲学：伤害从「别处」来。
- **适合**：咒术师、无痕者（暗影主类型）。
- **绑定**：布甲/皮甲混搭允许？**第一期不允许混甲**。只打布甲贤者线 + 魔典 + 暗影向饰品。
- **2 件**：暗影伤害 +10%（仅当英雄 `atkType == ATK_SHADOW` 时生效；否则退化为魔伤 +4%）。
- **4 件**：普攻不产生的仇恨再 −30%（乘法叠在夜猎者职业被动上要小心，建议对已有「仇恨降低」的职业改为魔穿 +8%）。
- **6 件**：每 8 秒开一扇「无光缝」：打当前生命百分比最低的敌人，伤害 120% 魔攻，**完全不产生仇恨**。
- **研究点**：和摘星星星人星门（2.6 秒 300%）比必须弱一个数量级。此套是「平民星门」，UR 仍是本体。

## 4. 不建议第一期做的套（备选池）

| 套名 | 原因 |
|------|------|
| 角色专属套（「大狗嚼套」） | 20+ 角色 × 6 件，制作和掉落都炸；和卡牌收集重复 |
| 品质套（「全传说激活」） | 逼玩家不换低级神器词缀装，和现有养成冲突 |
| 2 件小饰品套（双戒指） | 饰品只有 1 槽，做不了 |
| 原版「圣骑士的恩赐」点名套 | 职业迁移后名字会过期 |

备选主题若首发 8 套太满，可砍掉「万剑门扉」「无光星图」，留 6 套更干净。

## 5. 数据怎么挂（落地时按此，现在不写代码）

建议新文件 `scripts/config/EquipmentSetConfig.lua`：

```lua
-- 示意，非实现
SETS = {
  carapace = {
    name = "叠甲虫壳",
    pieces = { "A127", "Hxx", ... }, -- 或反过来 ITEMS[id].setId = "carapace"
    bonuses = {
      [2] = { stats = { { key = AD.HP_BONUS, pct = 6 } } },
      [4] = { talentId = "set_carapace_4" },
      [6] = { talentId = "set_carapace_6" },
    },
  },
}
```

更稳的挂法：**模板侧 `setId`，配置侧只写效果**。318 件里大约 120–160 件需要打标，其余保持散件。

结算时机：

1. 穿脱装备 / 进战斗建英雄时 `recomputeSets(hero)`
2. 2 件 → `addModifier("set_xxx_2", stats)`
3. 4/6 件 → 把 `talentId` 丢进现有天赋路由（和一转同一套 `TalentEffect`）
4. 换装立刻撤 modifier，避免残留

双手特例、套装冲突规则写在 `recomputeSets`，不要写在 UI。

## 6. 数值风险

- 6 槽已经把战力抬过一轮（头盔鞋子规划下调了旧 4 槽）。套装再加一层，**必须从「新机制」出强度，少出面板**。
- 2 件如果给 10% 伤，人人 2 件毕业，4/6 没人在乎。所以 2 件锁小属性。
- 跨甲水晶套若 6 件太强，职业甲种克制矩阵会作废。
- 和英雄天赋同触发（溅射、复活、飞剑、星门）是最大设计债，每套「研究点」落地前要逐条对 `TalentEffect`。

## 8. 请你拍板的问题（研究完回来勾）

1. 首发做 6 套还是 8 套？是否砍「万剑门扉 / 无光星图」？
2. 水晶套是否允许跨甲？
3. 双手武器满套按 5 槽激活 6 件 —— 同意吗？
4. 套装冲突时「只亮一套」还是「两套 2 件可以同时亮，4/6 互斥」？
5. 要不要角色专属套（我建议不要）？

本文只规划。你点选项后，下一轮再动 `EquipmentConfig` / `TalentEffect`。
