# 角色CG制作规范（觉醒页 · 影画切片）

> 觉醒页采用绝区零"意象影画"式设计：角色 CG 切成三竖条斜切错位排布，
> 未解锁灰度渲染、解锁显示原色。本文档约定 CG 的目录、画幅、风格与生产流程。

---

## 1. 目录与命名约定

| 文件 | 说明 |
|------|------|
| `assets/image/角色CG/CG_H<id>.png` | **正式彩色 CG**（手工/AI 绘制后放这里） |
| `assets/image/角色CG/CG_H<id>_gray.png` | 灰度版，**由离线脚本生成，不要手画** |
| `assets/image/角色CG/FALLBACK_H<id>_gray.png` | 回退源（立绘/卡牌）的灰度版，脚本生成 |

**回退链**（觉醒页 `resolveCG` 依次尝试）：

```
image/角色CG/CG_H<id>.png                    （正式 CG）
  → image/角色立绘/{角色名}_透明立绘.png      （立绘）
  → image/角色卡牌/KP_YX_<id>.png            （卡牌，无灰度，锁态用压暗代替）
```

> 正式 CG 一旦放入 `CG_H<id>.png`，觉醒页立即可用；灰度版重跑生成脚本即可。

---

## 2. 画幅与技术规格

- **比例/尺寸**：1:1 正方形，输出 **1024×1024**（2026-09-24 起；H1 仍为旧版 832×1248，切片按 cover 适配，不必重画）
- **切片几何**（面板 1080×2400 设计页，`ui/character/hero/AwakeningPanel.lua`）：
  - 三竖条各 **336×1150**，间距 12，斜切 30px，中条上移 36 错位
  - CG 按切片总宽**等宽适配**（cover），纵向取窗偏上（`V_BIAS = 0.18`）
  - 实际可见高度约 **77%**（脸部必须落在画面上 1/3～1/2 区间）
- **叠字避让**：
  - 每条切片**顶部 ~140px** 会叠罗马数字 + 阶段名（Ⅰ粗暴 / Ⅱ机制 / Ⅲ进化）
  - 每条切片**底部 ~80px** 会叠状态文字（已嵌合 / 可嵌合 / 未解锁）
  - 以上两处不要放脸部等关键内容
- **排版文字可被切**：CG 内的大字母排版被切片缝切开是影画风格的一部分，属预期效果

---

## 3. 风格规范（绝区零意象影画 × 暗黑魔塔）

1. **极近景特写**：角色头部/上半身充满画面，构图倾斜有张力；不要全身远景
2. **背景纯净**：纯色近黑暖调平面（≈ `#0D0B09`），**无粒子、无火星、无烟雾、无场景杂物**
3. **排版装饰**：大号骨白/暗金粗体英文字母（角色名拼音，如 `GOUJIAO`）+
   引号或几何色块，压在角色后方
4. **渲染**：赛璐璐平涂 + 粗黑阴影块 + 干净锐利的动漫线条
5. **人设一致**：生成时必须挂 `{角色名}_透明立绘.png` 作参考图
6. **色调**：整体暗黑低明度，用暗金 / 骨白提亮角色（与 DarkIcon 调色板一致）

## 4. 提示词模板

以大狗嚼（已验收）为例，替换 `【角色描述】` 与 `【拼音名】` 即可复用：

```
暗黑风绝区零意象影画风格角色插画。近景构图：【角色描述】；
上半身特写充满画面，构图倾斜。【姿态/道具描述】。
赛璐璐平涂上色，粗黑阴影块，干净动漫线条。
背景为纯近黑暖调深色平面（无纹理无特效），
仅有超大号暗金色粗体英文字母【拼音名】斜向排列作排版装饰。
整体色调暗黑，暗金与骨白提亮角色。高品质游戏插画
```

**要点**：负面约束（无特效/无杂物/无火星）必须写明；角色特征照抄透明立绘
（发色、瞳色、肤色、服装、标志物）保持一致。

## 5. 生产流程

```bash
# ① 出候选（batch_generate_images，model=gpt，reference=透明立绘，1:1 / 1024x1024）
# ② 用户选 1 张后落盘
cp <候选图>.png "assets/image/角色CG/CG_H<id>.png"

# ③ 重跑灰度生成（自动识别 CG 源，20 人全量刷新，已有 CG 的跳过重画）
python3 .cli/install-urhox-runtime.py --dest .cli
.cli/UrhoXRuntime _proc/gen_cg_gray.lua -tapcode_dir=/workspace -tool_mode

# ④ 布局验证（可选，离屏截图觉醒面板）
LIBGL_ALWAYS_SOFTWARE=1 GALLIUM_DRIVER=llvmpipe EGL_PLATFORM=surfaceless \
.cli/UrhoXRuntime _proc/render_awaken.lua -tapcode_dir=/workspace -tool_mode \
  -graphicssurfaceless -screenshot=screenshots/awaken.png -screenshot-frame=120 -x 540 -y 1200

# ⑤ 构建
```
