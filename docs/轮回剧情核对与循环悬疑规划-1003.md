## 1. 一页结论

### 1.1 推荐方向

**暂定篇名：《未寄出的撤离令》。**

一句话梗概：

> 第三十七任远征长不断带队穿过终焉之门，直到发现：铁匠遇到的劫掠者、苦等自己的镜像伙伴，以及曾经救回队伍的那道光，都与一份由自己签发的救援命令有关。自己越努力保证“下一次还能救”，旧伙伴越无法真正撤离。

核心问题不是“魔王是不是我”，而是：

> **如果救自己的人，也是让别人无法离开的人，我能否找到一种不再把救援欠到下一轮的方法？**

推荐情绪顺序：熟悉与轻松 → 似曾相识 → 身份不安 → 自救反噬 → 承认责任 → 共同破局。

### 1.2 借鉴的结构，不照搬的情节

借鉴《恐怖游轮》的三种叙事方法：

1. **不同时相的人同时存在**：玩家先看到结果，后来才知道另一个版本的自己为何做出那些行动。
2. **逃生行动成为困局原因**：主角为了救回伙伴签下特定命令，反而延长了他人的囚留。
3. **同一句话、同一个物证被重新理解**：首看是敌人的威胁，回看是失败救援留下的证词。

不照搬游轮、风暴返航、蒙面追杀、家庭悲剧、具体死亡循环或电影人物关系。舞台仍是现有山海远征、城镇、教堂、商队、古树与终焉之门。

### 1.3 本轮边界

- 全部 `SCENARIO_*`、`OPENING`、`OPENING_JOINS` 及战斗台词正文不改。
- 外祖父来信、正常开场、三人入队、角色 CG、觉醒、教程和奖励保持现有功能。
- 退役 `IntroCutscene` 旧时间轴、播放接线、输入/绘制/调试接线及专属素材。
- 五句旧过场独白存于本文附录，不迁成新的强制对白。
- 不调整三队共享生命池、英雄属性、掉落、挂机、难度数量或养成保留规则。
- 不生成视频、配音或新图片；本文只定义后续制作需求。
- 本轮只推新分支，不推 `workspace` 或 `workspace930`，不擅自合并。

## 4. 原创设定草案：不是整世界倒带，而是“续征”

> 本节是推荐的作者真相草案，需确认后才转为正文。

### 4.1 世界规则

“终焉之门”原本是公会在灾变后建立的远征保全设施。它会记录一支队伍的**登记身份、尚未完成的命令和可兑现的救援承诺**。一次远征结束，如果撤离手续没有完成，系统就签发“续征”，重新展开同一片远征区域的下一张记录页。

各难度是同一区域的不同续征页，不是不同地点突然全部同名。怪物变强来自裂隙和长期未结的救援负担，但**数值倍率仍由现有游戏配置决定，本文不追加隐藏惩罚**。

地理记录可以复现；已经经历过的人生和债务不会凭空被删除。因此，同一远征长可以遇见一支来自更早记录页、已经先一步走过更长旅程的队伍。

### 4.2 三个时相与身份规则

| 叙事称呼 | 身份 | 知道什么 | 不能做什么 |
|---|---|---|---|
| 此刻的远征长 | 玩家所跟随的当前队伍领队 | 保留当前连续旅程、养成和自己走过的轮次 | 不自动拥有另一记录页的完整人生记忆 |
| 灰印远征长 | 已经跑过若干续征页的同一登记身份；先前留下的高级时相 | 知道早期队伍会需要救援，准备物资与命令 | 不是全知；只能访问登记过的节点，不能任意传送、复活所有人 |
| 留门者 | 灰印远征长后期承担的职责，不另增加第三个无穷复制身份 | 知道怎样维持救援通道，也知道旧伙伴无法撤离 | 无权抹掉真实历史或强迫当前主角永远作出同样选择 |

**避免时间悖论的作者规则：**

- 不把过去、现在、未来写成一条绝对固定的万能时间线。这里是不同续征页的重叠记录，灰印者是已经存在的先行轨迹，不是玩家无条件必然成为的未来。
- 玩家看见的历史事件已经发生；结局不能回头宣布商队从未受害、旧伙伴从未被困。
- 破局是**不再续签新的囚留义务**并完成撤离，而不是删除既有历史或让证据失去来源。
- “第三十七任”是外祖父交接的任职身份；不同记录页复用此登记，不新增“第三十七轮”的说法。
- 同一姓名不等于同一当前肉身。当前三伙伴与旧伙伴都是拥有真实经历的个体，不以“只有一个是真货”裁定价值。

### 4.3 记忆规则

正常伙伴记得自己刚走过的旅程，当然知道正在第二轮，故63原文成立。系统**不强制擦除当前连续记忆**。

他们不记得镜像经历，是因为镜像属于另一张先行记录页，不是因为每次都把整个人生洗掉。跨页回响进入当前领队的感知时，只会形成不完整的场景/声音，70最初仍可被误认为噩梦。

大揭露必须靠记录、实物、第三方证词交叉确认；不允许“主角突然恢复全部记忆”替代调查。

### 4.4 传递限制

跨页交接只允许在预登记的**三个接驳节点**发生：林道路标处、城镇登记处、终焉门侧。每次开门只能处理一份明确签章的救援请求。

- 物资必须来自某个真实制作/存储点，记录物件唯一编号、修补痕和交接人。
- 一件物资不可在同页复制出两件；归还、投放、遗留都需要可追溯记录。
- 人不能随便穿页；旧队伍处于“未结任务”状态，只有有限地点与当前队伍重叠。
- 救援不是靠杀怪无限刷出来的时间货币；使用的是既有保全设施和登记抵押的有限救援配额。**首次救援由公会原始保全储备支付**，不是无来源地由未来救过去。
- 撤离抵押只取得既有配额的使用权限，不创造新配额；兑现一次就扣减一次。续征延长的是未结任务与担保占用，余额耗尽也不会自动解除囚留。完成交接须释放担保、终止授权并恢复撤离资格。
- 镜像倒下不自动等于被救、不自动抵消债务；**终止未结命令与恢复撤离资格是另一件事**。镜像战斗胜利只终止本次接驳中的战斗形态，不消灭被登记拘留的当事人；未结命令可在后续接驳召回其形态。最终交接由旧伙伴本人确认意愿，不能以死亡通知替代撤离签收。这条存续规则只适用于镜像，不能扩成全世界死亡都不真实。

### 4.5 神秘少女与魔王

**神秘少女：救援接驳员。**她能执行已经批准的保全请求，不能自行创造配额。38–40中的救人是真实的，但“继续赶路”来自一份要求受援队伍继续续征以维持通道的授权。她隐瞒了来源，也受制度限制；后续须正面承担隐瞒，而非一句“都是为你好”免除责任。

该授权覆盖的是这支登记队伍，不是一场固定日期的全灭。因此玩家从未失败时，新支线可以展示“尚未使用的救援保单”；不要求为了看真相故意团灭。原首次团灭剧情仍只在既有条件下播放。

**`？？？`：续征契约的执行者与受益者。**它利用未结远征维持门，不等同灰印远征长，也不必等同三只终焉守门怪。它知道“又”和“馈赠”的来源，但隐去真正出口。击败三守门者只取得一次记录页交接权，不是执行契约者已经永远消失。

原始山海灾变、公会建立保全设施的历史必须有独立起源记录；不能用一个无来源的时间圈解释所有东西。

## 5. 主因果链：救援与劫案为何是同一件事

### 5.1 作者按真实发生顺序掌握的事件

1. 灾变与保全设施先于当前故事存在，外祖父的交接是真实的。
2. 某条先行续征轨迹中，远征长与旧三伙伴被困，首次获得了一次跨页救援。
3. 远征长逐渐得知：要让早期队伍也能获救，必须筹齐保全物资与抵押配额。他决定“先救下来，手续以后补”。
4. 他签发紧急征用令，让旧伙伴截下商队。命令原本写救援目标，却放宽了拦截和缴械权限；镜像将士兵视为障碍。受害与错误不因为救援目的而消失。
5. 商队物资被送到登记节点；旧伙伴的撤离资格被抵押，转为未结任务。救援通道因此可持续开放，神秘少女能兑现批准的保单。
6. 旧伙伴在滞留中变形：大狗嚼把守护变占有，黄桃龙把陪伴变囚留，叮咚鸡发现“继续”并非撤离。
7. 当前远征长遇见劫案证词和镜像，以为只是敌人冒充；消灭镜像战斗形态并未注销其被抵押的登记。
8. 门继续把“救援已经成功”认定为续签理由，灰印者又筹备下一份命令。**循环由不断延期的撤离义务维持，而不是单靠反复杀人启动。**

### 5.2 玩家知道事情的顺序

```text
找回日志 → 铁匠说遇到相似劫匪 → 神秘少女救援/保单痕迹
  → 魔王说“又” → 镜像声称共同过去 → 噩梦中的狩猎
  → 找到商队征用令 → 对照自己尚未写出的签名
  → 看见灰印者筹备救援 → 明白旧队撤离资格被抵押
  → 发现自己已经获救，或尚未兑现的保单已经纳入同一救援链
  → 不抹历史，撤销无限续签并补完撤离
```

### 5.3 必须呈现的“自救瞬间”

在地狱/炼狱段，玩家第一次亲眼看见灰印者替早期队伍备好药箱、整理三人的名册。动作温柔、没有邪笑。他把一个迟迟未批的撤离申请翻到背面，写下“先救人，回来再结”。

随后的商队记录显示，这批药箱来自早期铁匠说过的被劫货物。镜头不靠旧濒死过场回放，也不用旁白直接宣布结论：**物件编号、命令印章、补写的同一句话**同时对齐。

此时才兑现主题：灰印者做出过救人的真实选择，也做出过让别人承担代价的真实选择。

**责任与身份的证据标准：**同一登记身份不等于此刻的领队亲手执行过。原令由第三方保存的签发底档、灰印者本人承认及其可观察的交接行动共同确认，单凭同印鉴不排除伪造。原始签令责任由灰印者承担，当前领队自愿接手补偿与解约签收。正常养成和接受尚未说明代价的救援，不构成玩家的过错。

## 10. 结局与游玩延续

### 10.1 推荐主结局：完成撤离

玩家集齐固定证据，由签发者、被抵押的旧伙伴、救援执行人完成同一份交接。物资来源经第三方登记核验，旧伙伴的经历被承认为真实，不再转移给新的队伍。

关键动作：

1. 承认原始征用与受害记录，不删掉它们。
2. 把仍占用的保全物资/权限按记录归还，不靠随机稀有物品缴费。
3. 收齐三人的撤离意愿与未结命令，停止自动续签。
4. 灰印者交出权限，神秘少女出示回执，当前领队承担最后一次签收。
5. 终焉门不再把这支队伍绑定到下一张续征页。旧伙伴选择离开，当前伙伴保留自己的身体、记忆与全部养成。

过去受害无法被时间魔法抵销，结局安排赔付与纪念，但不把赔付变成强制清空背包。

### 10.2 次结局：再借一次

若玩家在剧情选择中暂时不提交完整交接，执行者提供看似更便宜的续签方案。可以作为短支线结局/档案记录，不锁死主档、不额外发养成奖励、不让玩家为了全收集反复受惩罚。玩家之后仍可补证完成主结局。

### 10.3 通关后

剧情脱离续征束缚，与数值挑战解耦：重打关卡、副本、通天塔、养成、挂机继续可用。故事回看以档案为载体，不每次点击角色都强制重播。不新增16档难度，也不为结局清卡。

## 11. 贴合现有玩法的制作原则

- 主线仍自动战斗。调查发生在首通后和战前，不添加战斗中卡秒点击谜题。
- 证据固定获取，不靠低概率抽卡、付费神器、真实时间等待或必须团灭。
- 三队可以在一场剧情任务中分工为物资交接、身份核验、封门见证；**不把现有三行天然宣称为三个时间宇宙**，不改共享生命池。
- 六契职业作为世界隐喻使用，不以某个稀有职业构筑作为必看剧情门槛。
- 离线只保存收益和待阅事件，不让离线期间自动决定牺牲/签约，也不丢证据。
- 手动跳过不影响剧情解锁与奖励防刷；回看不重新领奖。
- 玩家养成不是原罪。特殊救援命令有责任，正常升级、掉落、招募和挂机仍是正反馈。
- 新角色显示使用独立 `portraitKey/actorKey` 规划，先解决情景与英雄ID混用，不能继续把数字4当魔王头像的可靠来源。
- 不恢复旧日志大页面。拟新增“远征档案”轻量只读入口，靠近功绩或剧情回看；具体位置作为后续UI任务确认。

## 13. 退役旧过场的技术说明

共享 `dialogue_blip.ogg`、`bgm_samsara.ogg`、开场三人CG、角色CG、地图和立绘保留。

### 13.2 安全切换

旧单场 `BattleScenePhases.process` 曾在局部pending尚未回灌时启动外部动画，动画结束才完成加载。简单换成同步完成会读不到pending；简单删除回调又会让加载的新关卡被旧局部状态回写覆盖。

本轮采用：

```text
终焉胜利 → 原2秒计时
  → Phases准备pending和本帧ready（不加载、不调用回调）
  → BattleScene回灌当前关、敌人、最高进度等全部字段
  → 默认completeReincarnation
  → 下一难度加载、阵容复位、天赋/BGM/切关通知
```

保留外部轮回回调接口，但移到回灌后通知；异步回调只在ready这一帧通知一次。正常单机不再注册旧动画回调。

三队协同胜利的 `completeTriTerminal` 逻辑保持，只删除它引用旧模块的模态守卫。
